# 告警规则：价格条件求值核心

对应可点击原型盯盘页「告警规则」「新建规则」与 v2 C12.1。最终仍需 P0–P3、池子/手动盯盘/板块/全市场范围、26 条筛选积木和盘中条件、频率与去重、受控保存/开关/删除、通知与页面接线，以及旧 monitor 四类规则对照后迁移。本片只建立价格条件的**真实求值核心**，不把它称为完整规则引擎。

**分级：普通任务。** 本片只在纯函数里解释已核验报价，不读写生产状态、规则目录或通知通道；风险是过期行情或未知范围被误判为触发。基线 `26818d1d`；验收只覆盖下述输入和输出，最终候选一次独立审查。

## 设计与验收

- 有类型的价格条件支持「达到或高于」「达到或低于」一个有限且大于零的人民币价格。输入为单只股票的已观察报价（代码、价格、观察时刻、交易日）、显式求值时刻、可信交易日与会话状态、可信范围成员集合和最大允许报价年龄。规则包含稳定 ID、名称、P0–P3 级别、启用状态及上海时间有效时段；不用裸字典跨层传数据。
- 求值返回明确的 `triggered` / `not_triggered` / `unavailable` 三态及有限的原因枚举；第一版价格条件只在上海时间连续竞价的半开区间 `[09:30, 11:30)`、`[13:00, 14:57)` 内比较，并进一步服从规则自身有效时段。14:57 起是收盘集合竞价，不能当作连续竞价（[上交所交易规则 2.4.2](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)、[深交所说明](https://investor.szse.cn/warning/t20190513_567105.html)）。只有启用、当日开市、代码在范围内、报价来自同一交易日且时刻不晚于求值时刻、价格有效并且未过期，才能比较。等于阈值应触发。休市、午间、开盘前、收盘后、暂停、范围缺失、过期/未来/错日/无效报价均不可触发；缺证据返回 `unavailable`，规则正常但不命中或未启用返回 `not_triggered`。非有限价格在输入校验时拒绝；绝不把未知当作零价或未命中。
- 这一层不确定范围来源、计算涨跌幅、控制频率、不写出信号或送达消息；后续接线必须为上述上下文提供真实证据。未来其他条件以同样的有类型输入/三态语义扩展，避免把页面草稿或旧 monitor 的文案当领域事实。
- 已知停用、休市、午休、有效时段外、股票明确不在范围或有效报价未越过阈值是 `not_triggered`；市场日状态未知、范围快照缺失、报价缺失/过期/未来/错日是 `unavailable`。输入模型自身违法（例如非有限价格、无时区时刻、无效代码）直接拒绝，调用者不得把拒绝解释为「未触发」。
- 聚焦红绿验证阈值边界、上海会话起止与午休、时区、报价年龄边界、未来/错日、停用、范围内外及缺失、非有限数值；Ruff 与 diff 检查通过。文档进度保持「部分且未发布」，不得在页面提前开放「新建规则」按钮。
