# 实验过拟合检查：DSR 纯计算核心

类别：普通任务。基于已审查的 PSR 核心 `6d0e829e`，只扩展 `rquant.overfit` 的纯计算与聚焦测试，不读写实验登记、研究产物或生产数据。主要风险是把试验总数冒充独立试验数，或把年化与单期 Sharpe 混用。

## 口径与职责

- DSR 按 Bailey–López de Prado 的论文 Eq. 1/2：在零真实 Sharpe 假设下，对 `N` 次**独立**试验的单期 Sharpe 估计标准差 `σ`，先算期望最大噪声门槛 `SR* = σ[(1−γ)Φ⁻¹(1−1/N) + γΦ⁻¹(1−1/(Ne))]`，再以既有 PSR 公式计算所选策略超过该门槛的概率。`γ=0.5772156649…`。`N=1` 的门槛定义为 0，此时 DSR 等于对零门槛的 PSR。
- 输入必须是同一频率的单期 Sharpe、所选策略收益的偏度与 Pearson 峰度、独立观察数、完整试验族的独立试验数 `N` 和该族 Sharpe 的单期估计标准差。把所选策略的 `SinglePeriodSharpeInput` 作为共用输入时，其比较门槛须为 0；函数内部生成新的门槛，不篡改输入。`N` 只接受整数、至少 1；不从裸试验次数、最优策略或缺失试验估算独立性。来源核验留给后续实验登记适配器。
- 拒绝布尔、NaN/Inf、负标准差以及导致非有限门槛的输入。结果明确返回输入、期望最大噪声门槛与 `[0,1]` 概率，不称“收益概率”或给晋级结论。无试验族完整记录时调用方不得展示 DSR。
- 继续使用标准库 `statistics.NormalDist`、既有 Pydantic 类型与 PSR 函数，不新增统计依赖，不把计算写进 Web/React。

## 验收

1. 对 `N=1`、`σ=0`、多个 `N` 与不同 `σ` 有独立数值对照；正标准差时门槛随 `N` 增大，DSR 不高于零门槛 PSR。论文给出的极值近似与现有 PSR 组合必须可复算。
2. 单期/年化、独立试验数、峰度/偏度口径明确；非法输入不返回看似有效的概率。输出保持不可变；原 PSR/MinTRL 的聚焦测试仍通过。
3. 测试先红后绿，Ruff 和最终候选独立审查一次。此片完成仍缺有效独立试验数估计、CSCV/PBO、真实收益/试验登记来源、产物、Serving 与 React，不得称 M8 已完成。
