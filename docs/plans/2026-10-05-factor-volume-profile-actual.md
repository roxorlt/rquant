## 原失败和修复

1. 首个面板没有历史日期时，覆盖诊断曾统计后续分钟。红测复现为 5 行；修正后为 0 行，原因仍是没有窗口日期。
2. 混合目录只选 VP 时，原依赖分支曾要求整个目录。红测复现后，将 VP 接入现有按实际依赖校验的分支。
3. 新诊断的空复权缺因日期曾省略，但输出 schema 要求该数组。现在输出空数组，并重新生成 OpenAPI 和 TypeScript。
4. 最大形状的初版样本缺市场来源；已补齐市场、竞价、分钟和股票来源，并加入 6 个原始行情字段。原容量合同未改。
5. 桌面测试曾在抽屉入场动画未完成时聚焦屏幕外控件。DOM 记录显示抽屉左边界为 1,440。测试等待抽屉完整入视口后通过，未改共享 UI。
6. loopback 和 Unix socket 初次被沙箱 bind 权限拦住。通过正常工具提权补跑。未绕过安全控制。

桌面失败的 trace 和页面记录保存在 `frontend/desktop-overflow-failure/`。
首次配置及测试样本失败的简要记录保存在本片验证目录。保留失败记录，不将它们写成通过。
