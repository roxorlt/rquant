# 因子来源逐日适配与单次执行

## 范围与冻结

- 父任务仍是完整交互原型与差距表补齐；本片落实来源到计算的依赖接线，不缩减每日多期限 IC、衰减、可信任务及真实网页运行的最终范围。
- 分类：普通任务。只新增本地、只读、探索性计算适配与执行器，复用既有来源合同，不涉及生产数据写入、权限、并发账本、部署或冻结生产契约。
- 直接代码基线：`1375db3a8eaec83ee8307394c7b455394a3bca1b`，集成树 `cdx-factor-source-integration`。本计划提交后作为实现树的冻结 base；实现树须干净且使用 `cdx/` 分支。
- 使用当前 Codex 原生实现者完成四文件，最终候选安排一次独立审查；普通任务最多一次集中定向修复及原审查者复核。根任务负责计划、进度、CHANGELOG 与固定测试清单。

## 用户能力与分层

在同一个已验证 v2 来源 session 中，由原始日线、复权与 SSE 日历生成逐日特征和收益，执行既有公式流，再执行既有完整横截面统计。一次调用选择持有 1/5/10/20 个开市日，先使用窗口不重叠的明确评估日程；不能把这种日程称作原型全部每日检验。

- Adapter 只负责来源读取、交易日映射、缺观察与收益事实；公式、股票池选择和统计仍由各自领域模块负责。
- Runner 只负责一次准入和顺序执行、绑定与结束证明、清理；不引入通用调度框架或 Web/worker 写入。
- 跨层请求、结果和完成证据均使用严格、不可变、重验证的 Pydantic 合同。返回只含有界逐日统计和摘要，不保留全期逐股矩阵。

## 请求、日期与来源合同

1. 严格请求绑定定义、四种股票池选择、完整固定计算代码超集、计算日程（含预热）、评估日程、持有期限、分析截止时刻、v2 snapshot/binding/scope 摘要与证券/指数归档身份。计算日和评估日使用已有有限上限。分析截止不晚于冻结来源截止，两个时刻均保留。
2. 只使用公开的 v2 准入和 lease 固定三表读取 API；同一执行代、同一连接，单次查询仍最多 500 股、366 自然日、100,000 行。所有代码、前置面板日、收益端点及成熟日须在来源范围内；不能开放任意 SQL 或直接访问私有连接。
3. 决策日 D 的公式特征来自上一 SSE 开市日 P(D)，映射到 D。可见时刻沿既有适配器使用 D 09:25 的历史回溯假设，明确不是实际历史采集/PIT。原始行缺失、字段 NULL 和有效数值分别保留为 missing_observation、known_null、value；纯时序计算始终覆盖固定计算超集，历史横截面由每天真实选择输入决定。
4. 一次性股票池来源须精确覆盖每个计算日，包括预热日；索引池需同日完整成员。固定证券/指数归档身份和实际观察时刻按既有公式/选择合同验证。调用方 SHA 仅绑定输入，不证明提供方真实性或覆盖完整；本片使用合成归档作行为证明，真实可信归档接通继续保留。
5. 持有 H 日的端点是 D 后第 H-1 个 SSE 开市日。收益为 `close_end*adj_end/(open_D*adj_D)-1`，结束时刻为端点 15:00，成熟时刻为随后 SSE 开市日 09:25。未结束、待可见、缺价格、停牌、缺/非正/无效复权分别沿既有收益合同输出空值及原因，不能填零或提前可用。
6. 组合评估日程不重叠，沿用旧统计模块检查。原型每日滚动多期限 IC/衰减另行冻结纯统计口径，不能放宽旧组合不变量或按稀疏样本替代每日结果。

## 完成与清理

逐日事实都是中间结果。Runner 只有在适配器、公式流的完整日程和源尾部均已自然排空、统计成功且全部绑定一致后才返回不可变最终结果。统计最后一日之后仍须排空后续计算/预热日及源尾部；缺批、额外批、尾部异常或取消不能留下成功完成证据。

适配器记录实际读取的有界逐日摘要与缺数计数/来源摘要；执行结果同时保留 adapter completion、formula completion 和统计结果。成功及失败路径均关闭自有迭代器和唯一 session，临时副本实际清理；调用方尚未消费完的流不能称作完成。若现有公开 API 无法满足必须条件，先报告具体依赖，不自行扩大写集。

## 可验证验收

- 先有真实聚焦红测，再实际运行最终相关测试，复用仍有效结果。四个持有期限与旧适配器/批量可比结果对照；动态股票池及历史横截面使用手算样本核定，合法空池和缺失归档分别验证。
- 日期范围、缺日历、截止、成熟边界、NULL/缺行、停牌、价格及复权错误有对应行为证据；错 request/source/selection/generation、超容量和窗口重叠实际拒绝。
- 最后评估批之后的源异常、缺批、额外批、未排空和显式取消不能产出最终成功；完整自然排空可产出互相绑定的完成证据。成功和错误都验证连接/自有流关闭、临时副本清理。
- 同一 session 实际读取至少 16 日 × 7,000 股完整计算超集，累计超过 100,000 日线源行，无截断；源对象按日释放并记录有界合成内存证据，不能称作真实约 10 GB、RSS 或生产性能证明。
- 最终只运行新增和直接受影响模块的聚焦回归、Ruff/format/diff-check。记录命令、实际 Python 版本、exit code、passed/skip/deselect；Python 3.11 如仅语法检查须明确。不自动全仓回归。
- 最终候选清晰记录 base/candidate 和文件边界，独立审查一次性覆盖全部写集、直接依赖及上述验收。清单只追加新用例，必要的精确收集门禁由根任务处理。

真实只读副本路径、成员归档与正式元数据注入仍须接通。本片验收后继续每日多期限 IC/衰减、可信任务、原型运行/跟踪与真实规模验证，整体 goal 保持未完成。
