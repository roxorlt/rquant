# 因子研究页：新建与编辑定义

接续受控保存 Web 命令，把原型因子库的「新建因子」「编辑」做成真实交互。**任务分级：普通任务。** 本片只消费已认证保存接口及只读字段能力，不在浏览器解析或计算因子，不改写命令安全边界；最终候选做一次独立审查。线上入口及 Streamlit 迁移另行验收。

## 页面合同

- 仅当前因子库已核验、保存入口已启用且当前用户是编辑者时显示「新建因子」；可信空库也能新建。未开放时保持清楚的空态，不显示看似可用的假按钮。当前未归档定义才有「编辑」，打开时从同一数据代装入名称、分类、方向和表达式；旧版本和已归档版本不能静默覆盖。
- 表单只让用户编辑四项：中文名、分类、方向、表达式。新建 ID、版本、字段目录、依赖和历史窗口全部由服务端决定。六个可用日线字段以中文名和简短提示辅助插入，算子帮助放 `Tip`；暂缺历史上下文的行业/市值算子不提供快捷插入。页面明确“保存公式后，实际数据范围在检验时核对”，不把代码能力写成数据已覆盖或今天可运行。
- 轻量客户端输入反馈要具体到字段，真正解析和准入错误以服务端为准；原始表达式作为纯文本处理。新建直接「保存因子」，编辑用「保存新版本」并提示旧版本保留。保存后保留原命令身份；处理中与“已提交，等待更新”分别显示，只有更晚的同实例数据代证实对应 head 才显示“已保存”。超时、刷新和多标签后用原命令续查，绝不暗发第二笔；失败保留草稿供修改。数据代变化时不把旧 head 静默升级，先提示刷新并重新比对，草稿不丢失。
- 页面正文只显示用户需要的名称、字段中文名、版本和可操作状态；内部 ID、摘要、数据代、服务名仅在必要提示/详情。日期未知写“待检验”，历史日期只作“记录起日”；缺数不画零。桌面双栏和 390px 单栏均能完成新建、编辑、保存状态恢复；键盘焦点和字段帮助可操作。

## 验收

用合成 Serving/API 夹具验证可信空库新建、当前版编辑、同代确认、换代时保留草稿、写入超时原命令恢复、CAS 冲突、非编辑者/入口关闭、已归档定义、非法公式以及 390px/键盘流程。`findJargon` 检查正文，运行前端聚焦检查、构建及产物一致性；浏览器只跑新建→编辑→续查的桌面/手机目标路径。未经生产授权不切流、不停 Streamlit。
