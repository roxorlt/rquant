## 用户路径

1. 打开查询页，查看实际可用的只读数据表和短字段说明。未安装时显示具体可理解原因。
2. 输入 SQL，运行或查看执行计划。结果带数据时刻、返回行数和实际耗时。空结果与执行失败分开；新请求不能被旧响应覆盖。
3. 导出当前成功结果的 CSV。超过限制时明确只返回部分结果；CSV 与屏幕数据来自同次结果。
4. 命名保存常用查询，载入后仍由用户运行。提交回执和持久保存结果分开；不确定回执可按原命令恢复。

中文文案短而直接。SQL、表名和字段名是本页完成查询所需的信息；内部服务名、路径、数据摘要和权限实现放合适的详情，不放页面正文。支持键盘、390px、错误、加载与空态。

## 设计边界

- React 展示和交互，网页 API 鉴权与转发。API 进程不打开副本，不执行 SQL。
- 独立查询进程只在显式私有 Unix socket 接受请求。复用现有 peer UID、目录身份、文件模式及有界消息校验，不接受任意 TCP 或浏览器提供的 owner、角色、数据库路径。
- 使用现有受信用户身份。入口默认关闭，服务端显式 researcher/admin 准入名单在 API 与私有服务两端一致；普通 viewer 和未授权身份拒绝。名单按现有身份合同实现，不能仅信任客户端头。C15 的完整角色管理不在本片扩大实施。
- 用户 SQL 只连接专用公开行情查询快照。离线受信 producer 从核验副本或具名研究原件按下表生成独立 DuckDB；保留原来源身份、日期范围和本快照摘要。Web API 和执行子进程都不打开完整主副本、Serving 库或控制库。快照加载时核对实际全部表、字段、类型和对象；额外表、字段、view、macro 或函数均拒绝，不能只检查用户 SQL 写出的表名。新连接失败或来源变化明确失败。研究湖仍走具名可信读取，不能开放 read_parquet 或 ATTACH 给用户 SQL。
- 沿用 `_validate_bounded_select` 的 32 KiB、单条 SELECT / WITH 准入。用 DuckDB 实际 statement 类型确认只读；CTE 写入、多语句、文件读取、扩展安装、配置语句和外部访问拒绝。守卫不能仅依赖关键词正则。
- DuckDB 在连接创建时设置 `read_only=True`、`enable_external_access=false` 和适当 memory_limit、threads、私有 temp 根，随后锁定配置。SQL 无法启用外部访问、写库、载入扩展或更改资源限制。
- 每次执行在独立子进程中完成。在导入 DuckDB、打开来源或处理 SQL 前设置硬 `RLIMIT_AS=2 GiB`、`RLIMIT_FSIZE=512 MiB`；实际内核限制无法生效时入口拒绝运行，不用采样 RSS 代替硬上限。DuckDB 同时设 `memory_limit=512 MiB`、`max_temp_directory_size=512 MiB`、1 个计算线程并锁定配置；每请求使用独立私有临时目录。512 MiB 是该请求全部 DuckDB spill 的上限，FSIZE 再约束单个文件。结果及 IPC 文件受 16 MiB 合同限制，子进程只能写受信代码指定的临时文件；用户 SQL 外部文件访问关闭。
- 父进程执行 30 秒 deadline，超时或取消后中断、必要时 kill 并等待退出；连接、FD、子进程、临时数据正常收尾。服务同时执行最多 2 个请求、等待最多 8 个，满容量明确拒绝。客户端不能提高上限。子进程使用最小环境及关闭继承 FD，不继承凭据。生产 slice 的额外总量限制在装机验收另行核验，代码验收先实际证明上述内核和 DuckDB 限制。
- 结果最多 10,000 行、16 MiB；16 MiB 包括完整序列化结果，不只计算原始单元格。按有界批读取和累计实际字节判断；私有消息同样有界。超限、非有限数、Decimal、日期、二进制及重复列名有明确有类型表示，不靠巨大 fetchall 再截断。执行计划通过受信模式生成 EXPLAIN，用户输入仍只准 SELECT / WITH。
- 保存使用有类型 `save_research_query` 命令，复用 PageControl 的身份、CAS、原命令恢复及同事务效果/回执模式。每用户最多 100 份、名称最多 60 字、SQL 最多 32 KiB；同 ID 冲突、跨用户访问及版本冲突明确拒绝。只有确认权威写入后页面称已保存。
- 计算服务只读。保存与列表由已有控制面或明确的私有写入桥处理，查询沙箱不能取得控制面凭据或自行提交操作。
- CSV 由成功有界结果生成；按标准 quoting 输出，防止电子表格把用户结果的公式前缀作为可执行公式。页面用文本渲染，保持 SQL 和结果内容，错误不暴露凭据或服务端路径。

## 冻结的资产与失败模型

资产：生产主库、只读副本及其身份、研究/Serving 快照、`.env` 与密钥、控制面状态、每用户保存查询、服务资源及其他页面的可用性。

信任边界：浏览器输入 → 认证 API → 核验私有 socket → 独立受限子进程；保存走认证 API → 私有控制面。浏览器 SQL 和名称均不可信；服务端来源配置、身份和固定代码受信。

公开 SQL 对象只有以下三表；服务内部 sqlite、快照 metadata、通知、账号、用户盯盘、任务及研究产物均不在查询库。目录只列实际发布的这些表和列。

| 表 | 允许字段 |
|---|---|
| daily_bar | ts_code、trade_date、open、high、low、close、vol、amount |
| adj_factor | ts_code、trade_date、adj_factor |
| trade_calendar | exchange、cal_date、is_open、pretrade_date |

producer 对源字段按明确列选择，类型沿原数据合同；在私有目录构建、核验后原子发布查询快照。配置加载先复核 manifest 和完整文件摘要，固定该只读文件身份；每请求核对身份和实际 schema，变化后拒绝，重新载入核验快照。既有大副本不是查询快照，直接传入须失败。后续新增公开数据按明确字段合同增量交付，不能通过原库 alias 暴露隐藏数据。

必须保持：

| ID | 不变量与实际失败用例 |
|---|---|
| RQ-01 | 无身份、viewer、伪造身份/角色、普通 TCP、错误 peer UID、错误 socket 身份均不能执行或保存。使用实际私有入口验证。 |
| RQ-02 | 用户 SQL 不能写数据、读任意文件、联网、载扩展或改配置。用 INSERT/CTE、多语句、ATTACH、COPY、read_parquet、read_csv、扩展及配置语句验证，并核对源字节不变。 |
| RQ-03 | SQL 的有引号内容、注释、CTE 与解析器类型不产生准入漏洞。合法读取可运行；非法实际 statement 拒绝。 |
| RQ-04 | 实际慢查询达到 deadline 后子进程退出并 reaped。实测整个子进程地址空间上限，包含 DuckDB memory_limit 管不到的单行字符串、输出转换和 Python；实测 spill 总量/单文件及私有目录收尾。硬限制设置失败或不受支持时拒绝运行。成功、失败、超时及连接错误后 FD、线程和 scratch 无增量。可注入较小测试上限/deadline，但不能抬高生产上限。 |
| RQ-05 | 行数、16 MiB 与进程/排队容量有效。实际跨越边界的返回有明确 partial 状态，父进程不接收无界结果；宽行、二进制和非有限值覆盖。 |
| RQ-06 | 来源变更、坏 manifest、非核验路径、额外表/列/对象及锁失败明确拒绝。计算回执与实际来源相同。用含其他用户盯盘/通知的合成原库证明这些内容没有进入公开快照；main/schema-qualified、CTE、dynamic query、query_table、table function 和元数据搜索均无法读取那些私有数据。加载完整 Serving/主副本失败。 |
| RQ-07 | 保存的 owner 来自受信身份。同 ID 重试无重复效果；同 ID 不同 payload、跨用户读取/续查、CAS 冲突、容量拒绝及事务失败保持原数据和完整回执。 |
| RQ-08 | 结果文本不执行 HTML/脚本，CSV 公式前缀不执行；重复列名、空结果、错误、旧响应、移动端和键盘仍可正确使用。 |

排除：外部模型、任意 Python 执行、任意文件源、数据库写 SQL、生产数据修复或回补、云 Notebook 装机、HTTPS 与其他生产基础设施变更。

阻断仅限上述不变量和本页验收。范围外问题单独记录。新增信任边界或失败假设先更新本模型；不进行全仓安全审计。
