# 协作、权限与结果导出实施计划

**目标：** 完成原型的用户与权限、操作记录和只读结果导出。

**架构：** 身份继续来自原私有入口。PageControl 管理角色和写入命令；Serving 发布只读视图。导出读取原封存结果，不另算一份结果。

**状态：** 本地候选已获原审查者接受，四项最终问题全部关闭。原角色操作、原审计和三类完整离线报告已通过当前桌面及390px验收。物理身份隔离、Linux安装及正式切流继续完成。

## 1. 验收目标

| 原要求 | 用户能做什么 | 验收重点 |
|---|---|---|
| C15.1 | 管理员从“我的 → 用户与权限”查看和修改角色 | 后端实际放行；两步确认；撤权生效 |
| C15.2 | 按人、时间和动作筛选操作记录 | 记录来自原命令账本；请求与结果可核对 |
| C15.3、C7.3 | 导出回测、因子检验等只读结果页，在本地打开 | 内容完整；数值来自原产物；不需要网络 |

页面使用短中文。身份、版本和摘要只在需要核对的详情里展示。桌面支持键盘；390px 支持触摸和完整筛选。关闭对话框后返回有效入口。

## 2. 风险与不变量

本任务为高风险任务：涉及权限修改和私有结果读取。只检查下列边界。

| 边界 | 失败路径 | 必须保持 |
|---|---|---|
| 身份与角色 | 浏览器自报管理员；旧角色缓存继续放行 | 只接受原入口身份；写入使用当前权威角色 |
| 角色修改 | 旧确认覆盖新策略；重复请求再次修改 | 两步确认绑定当前版本；原 UUID 和正文先核对 |
| 撤权与恢复 | 换账号读旧内容；撤权后恢复写入 | 当前身份和权限先核验；不借原请求绕过撤权 |
| 操作记录 | 用访问日志冒充操作结果；跨用户泄露 | 读取原命令事实；按当前权限过滤 |
| 结果导出 | 错产物、错数、路径逃逸、外部脚本 | 原用户与产物摘要绑定；读取封存材料；本地页面不请求网络 |

不新增登录系统、公开免登录链接或消息发送。生产账号、初始管理员和角色文件安装继续走既有生产授权；开发材料不读取真实凭据。

## 4. 实施顺序

### 4.1 角色与权限

由原 PageControl 管理 `data/runtime/control/web/roles.json`。角色只有 `admin`、`researcher`、`viewer`：管理员可管理；研究员可读和提交研究任务；查看者只读。

先按整合后的准确接口列权限表，明确研究写入、运维写入、敏感日志和角色管理。新接口没有明确规则时不自动放行。前端隐藏按钮，后端仍独立核验。

增加 typed `set_user_role`，沿原命令和恢复路径做两步确认、版本比较及审计。原命令正文摘要和旧恢复语义保持。角色缺失、损坏或不明确时不推定为管理员。初始管理员通过明确的安装配置指定，不由第一个访问者获得。

### 4.2 操作记录

从原命令账本发布 `command_audit`。显示操作人、时间、动作和结果；请求编号及详细原因放详情。支持分页和人、时间、动作筛选。

管理员按明确权限查看全局记录；其他角色按权限查看自己的记录。没有结果时显示待确认，不能把已接受请求写成执行成功。不建第二套命令队列，不复制一套命令状态机。

### 4.3 只读结果页

在原回测和因子检验结果页增加“导出只读页面”。读取已成功封存、当前用户有权读取的原结果。优先复用原 HTML；若原材料依赖外部资源，补自包含渲染，但计算和数值仍来自原产物。

输出包含结果概况、图表、参数、数据范围和必要的来源说明。标题及文本转义；不得带密钥、内部目录、可执行命令或外部网络资源。文件在无网络环境可打开；不能因关闭网络丢图表。

导出绑定原任务、用户和产物摘要。原材料缺失或损坏时给出短提示，不生成替代数据。继续复用原受控产物读取和导出存储，网页 API 不获得任意文件读取或写入权限。

### 4.4 聚焦验收

先验证权限拒绝、撤权、旧确认、同请求恢复和跨用户读取，再验证正常角色操作、记录筛选和封存结果导出。高风险失败用例在实现前冻结；不扩成全仓审计。

实际生成 OpenAPI 和 TypeScript。最终构建后验证桌面与390px：角色修改两步、取消、焦点返回、换账号、操作筛选、导出；再在无网络浏览器打开真实导出文件，核对原数字、图表和外部请求为零。
