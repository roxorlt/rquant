## 本片交付

1. 新增独立 builder/contract version，绑定日线、复权因子、SSE 日历与一个计算范围 artifact。明确的固定计算代码超集最多 7,000 股；范围 artifact 的完整代码、日期范围与截止时刻受到文件和逻辑内容哈希保护，不能只记录股票数量或让调用方自填覆盖承诺。
2. 从 builder 控制的同一只读事务物化三表，记录真正的冻结来源身份；标记 `historical_retrospective`，不声称实际历史采集时间或 PIT。日期范围使用独立的有限上限（最多 4,096 自然日），逐次查询仍遵守原 366 自然日上限，不能把交易日数量与自然日跨度混用。
3. 新版准入严格核对版本、精确四项 artifact、范围、来源摘要、文件与执行代。v1 binding 不能被当作 v2，v2 不能进入旧 v1 租约或旧任务准入。
4. 新版 reader 只接受范围内代码和日期。每次固定三表查询仍最多 500 股 / 366 自然日 / 100,000 行；全程复用同一个已验证 session，支持按日与代码分组的累计读取。不开放任意 SQL 或新的直接数据库连接。
5. source preparation 与公式、股票池、统计保持分层。本片原始来源仅三表，不补造上市/ST/板块/指数事实，不开放网页检验或跟踪写入口。
