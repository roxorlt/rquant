# IC 衰减进入因子研究结果

接续纯 `FactorICDecayResult` 与 `FactorResearchResult`。**分级：普通任务**：改变本地尚未封存的因子研究结果模型，不触及生产数据、权限、并发或已发布合同。当前衰减只可单独调用，未来 Lab 若只封存研究结果会遗漏原型因子页必需的 1–10 期衰减。

## 合同

- `assemble_factor_research_result` 从同一已验证 `FactorResearchRequest` 计算 IC 衰减，把完整有类型的 `FactorICDecayResult` 作为 `FactorResearchResult.ic_decay` 的必需字段。定义版本、两种来源 ID、收益口径、持有期、股票池、评价日期和 `as_of` 必须与主结果一致；研究结果的内容摘要覆盖衰减字段。不得把缺目标期、未成熟收益或无有效样本变为零值。
- 不更改单期 IC、覆盖率和分组诊断；不引入新的数据读取、页面假数据或任务调度。终审发现原主结果对语义无序的观察行直接做摘要，而衰减先规范排序：反转合法输入顺序会使两者的 `input_sha256` 不一致。定向修复应让两者共用同一个规范请求摘要，且语义相同的行重排保持同一输入身份和主结果内容摘要；这项证据修订了原先“主结果输入摘要不变”的限制。若重复计算的实际负载以后成为瓶颈，再凭测量共享中间值。
- 合成数据红测核对首期与主结果对应、后期用基础日因子对目标期收益、无目标期/无有效样本状态、内容摘要随衰减事实变化，以及同一输入重复计算稳定。针对 `FDRI-FINAL-01`，反转合法观察行与收益行后核对主结果和衰减的输入摘要相等、结果摘要稳定；运行原聚焦用例、Ruff 和 diff，仅由原审查者定向复核。

本片完成后 Lab 封存产物可直接携带衰减；Serving 和 React 仍需后续接线。
