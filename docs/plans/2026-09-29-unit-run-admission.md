# 任务页「立即运行」：受控准入首片

任务页已有只读总览与日志候选，原型里的「立即运行」仍无真实动作。本片先冻结将来 root 运维服务执行前必须满足的纯准入规则；只做无 I/O 的领域判断，不启动 systemd、不写主库、不开放 Web 按钮或 API。**分级：高风险**，因为错误准入最终会启动可能改写生产数据的共享 systemd 单元。部署单元、权限、生产策略和实际启用另行形成候选并按项目规则单独授权。

## 威胁与失败模型

- **资产及边界**：用户身份与两步确认在 Web/PageControl 边界建立；已签安装清单和 root 持有的策略在运维服务边界建立；systemd 当前状态、权威 SSE 交易日及持久审计中的上次启动时刻由各自可信来源提供。浏览器传入的 unit 字符串、时间、任务类型和运行状态均不构成权限证据。本片仅消费这些边界未来提供的有类型快照，产出允许或封闭拒绝原因。
- **失败路径**：任意或别名 unit 触发未列出的服务；策略关闭、清单变化或状态不可读时仍放行；正在运行的单元重复启动；工作日 09:15–15:10 启动会写主库的任务；绕过单元自己的时间窗或最短间隔；将“未取得交易日/时钟/上次启动证据”解释为安全；评估与实际 StartUnit 之间状态变化；审计失败却执行。
- **不变量**：只认策略中确切 `.service` 名与固定分类，所有数据缺失或矛盾时拒绝；写主库类默认关闭，明确开启后也不得在已知交易日的 09:15（含）至 15:10（含）启动；任何单元运行中、上次启动间隔不足、超出允许时间窗、系统状态未知均拒绝。准入结论只针对同一个不可变证据快照，不授权执行层跳过启动前重验、持久审计和互斥锁；执行层必须按原子顺序审计、重验、启动并写结果。页面不能把准入允许当作已运行成功。
- **排除**：本片不证明快照来自受信来源，不生成确认令牌，不实现 root daemon、D-Bus、socket、审计、系统安装、Web/PageControl 命令或生产运行；不修改 `deploy/systemd/`、`deploy/nginx/`、`deploy/sudoers/`。这些环节完成并获得必要的单独授权前，「立即运行」按钮保持隐藏。

## 纯规则契约

- 策略是有界的确切 service 条目，包含 `enabled`、`effect=read_only|writes_primary`、上海时间的非跨日允许窗、正整数最短间隔；不从名称前缀或可执行文件推断作用。输入给出期望 unit、唯一策略条目、带时区且归一化的评估时刻、与该时刻对应的 SSE 交易日判断、systemd 当前 active/running 状态、持久审计的上次启动时刻和写者互斥状态。任何字段不得由浏览器自由声称为可信。
- 拒绝结果使用封闭枚举，前端只显示简短中文解释；不包含内部路径、任意异常或原始命令。对未知交易日一律拒绝。最短间隔以实际持久启动时刻计算，未来时刻/不一致证据拒绝。写主库类在互斥状态未知或已占用时拒绝；只读类也需要明确的 systemd 状态。
- 时间窗按 Asia/Shanghai 墙上时间比较；定义为左闭右开。工作日盘中禁写区间另按左闭右闭比较，避免边界秒误启。周末和明确休市日仍须遵守单元自己的窗口与开关。

## 验收

1. 表驱动红绿用例覆盖确切匹配、任意/别名 unit、禁用、运行中、状态未知、缺交易日、跨时区时间、时间窗两端、最短间隔边界、未来审计时刻、写者互斥以及交易日 09:15/15:10 边界。
2. 输出稳定、可序列化且不含自由文本；同一快照重算相同。只运行直接相关测试、Ruff 与 diff 检查；最终候选一次独立高风险审查，限定上述失败路径。
3. 后续服务须另证其签名策略、可信取证、启动前原子重验、持久审计、实际 systemd 执行和 Web 确认链；本片通过不等于 C13.3 完成或生产可用。
