# 数据中心剩余工作

状态：范围已整理。尚未开始实现，也未通过本片规格审查。

目标对应 CC v2 的 C1.1–C1.4。沿用已验收的 24 类目录、统计、审计任务和页面。补齐采集完成联动、实际回补、财务采集与正式安装证据。

本片为高风险任务：涉及生产数据来源、恢复和写者互斥。本次不限制执行时长或修复次数。只处理下列范围内的问题。

## 1. 采集完成后触发审计

使用原采集和入库回执。将它们与实际副本的身份、内容和覆盖数据集绑定，再提交原审计队列。

- 原 `DailyCanonicalPublishReceipt` 已记录日线提交、来源、日历和各表内容。使用这份实际回执。
- 原日线 shadow 运行报告只能证明影子运行。它不能证明主库已写入。
- 副本文件摘要只能固定读取内容。它不能单独证明采集已完成。
- 每个数据集只展示自身已核验的完成状态。日线回执不能证明分钟线或财务采集完成。
- 已受理事件持久保存完整请求。响应丢失、进程重启或副本换代后，续查原任务。
- 同一事件只创建一个任务。同一身份对应不同内容时拒绝。
- 原有 `production_unverified` 报告继续可读。缺少有效回执时，页面仍显示“待核验”。

验收必须经过原采集／提交回执 → 副本证据 → 原队列 → 原 worker → 封存报告 → Serving → 网页。仅调用新函数或构造报告不算接通。

## 2. 执行已生成的回补计划

沿用[已冻结的回补契约](2026-09-27-backfill-plan-web.md)。计划只处理列出的日线整日空洞。

- 页面提交原计划 ID、内容摘要及两步确认。日期和写集由已封存计划决定。
- 执行策略默认关闭。服务端核对权限、真实额度、计划来源、允许时间窗和唯一运行任务。
- 原区间 CLI 会遍历整段并替换部分既有行，不能直接作为本片执行器。
- 复用原取数、证券状态、派生计算和租约。执行器按计划的精确日期逐日处理。
- 取得公共排他锁后，再核对主库。原日线、监控、备份、副本同步及手工入口须参与同一互斥规则。
- 日线事实与该日回执在同一原 DuckDB 事务提交。已有正确关联行保留；冲突拒绝。
- 崩溃后核对原回执和内容，再跳过已提交日期。无本任务回执的新增日线不能当作本任务成果。
- 剩余日期、派生重算、副本刷新和新审计都通过，才显示“回补完成”。

时间窗沿用原契约：上海时间工作日 17:50 后或周末。工作日 08:20 前停止接新日期，08:30 前释放锁。跨窗在日期边界暂停，下一窗口恢复同一任务。

估算和实际观测只表示适配器的逻辑操作数。真实 HTTP 次数或扣额未知时，保持未知。

## 3. 接通财务来源和每日派生

已有七接口采集、不可变观察记录、PIT 选择、六字段每日派生和选股接线。补充实际运行装配和安装证据。

- 沿用 `fina_indicator`、`income`、`balancesheet`、`cashflow`、`forecast`、`express`、`dividend` 的原采集器。
- 每次修订保留首次观察时刻。历史检验同时核对公告可见时刻和实际观察时刻。
- 沿用原 SSE 日历、不可变版本和来源回执。缺公告、缺日历、缺权限或缺字段时显示未知。
- 每日派生仍用原 PE、PB、股息率、ROE、营收同比和净利同比计算。页面不得另算一套。
- 页面显示最近可用时点、覆盖数、缺失原因和需要处理的问题。接口代号与摘要放详情或提示。
- 七接口的实际权限、额度和来源覆盖分别记录。不能用一个成功接口证明其余接口可用。

## 4. 实现和验收顺序

1. 实现者核对下方来源清单，补全具体装配、容量和失败用例，冻结规格。对本片规格做一次独立审查。
2. 在同一任务工作树完成上述三条原链路及页面。旧默认行为保持兼容。
3. 先运行相关红绿回归。Root 执行需要独立进程、浏览器或 Linux 的实际验证。
4. 对最终候选做一次独立审查。只修当前验收阻断项，并复用仍有效的证据。
5. 准备完整安装、验证和回退材料，再提交需要单独授权的生产变更。

本地代码、合成测试和已有只读诊断可继续。生产数据库写入、新 unit、sudo、凭据、正式切流及 Streamlit 停服遵守项目已有的单独授权规则。

## 5. 本片验收边界

| 验收项 | 必须有的结果 |
|---|---|
| 完成联动 | 原始实际提交和副本证据触发唯一审计任务；缺失、失败或 shadow 证据不显示生产完成。 |
| 恢复 | 任务受理、事实提交、发布和回执丢失后，恢复同一身份；同身份不同内容拒绝。 |
| 回补写集 | 只写计划日期；正确既有行保持原样；外部写入或内容冲突拒绝。 |
| 互斥与时间窗 | 两进程争锁、旧写者在运行、跨窗及截止前请求均按原契约等待、暂停或拒绝。 |
| 财务 PIT | 七接口走原采集器；新观察的历史修订不提前可见；每日派生和选股使用同一来源。 |
| 页面 | 桌面、390px、键盘和触摸可完成实际操作；排队、进行中、暂停、失败、部分完成和完成可区分。 |
| 正式替代 | 实际安装、数据代和资源验收完成；未经授权不写生产库、不停旧服务。 |
