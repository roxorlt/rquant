本文件只记录已经有行为证据的交付状态，功能范围与验收以 [平台方向决定](2026-09-26-react-platform-decision.md)、CC 的可点击原型、`frontend-plan-v2.md` 第 4 节及差距表为准。原型中的可见操作都须接通真实行为；差距表中的「缺」「部分」，以及 M4、M12 虽标「已有」但列出的缺口，都在最终范围内。M11 实盘交易排除。

## 完成标准

- 页面按原型的使用路径工作；空态、加载、错误、窄屏、键盘和中文文案遵守 `web/AGENTS.md`。技术编号和服务代号不放在页面正文。
- React 负责交互和展示；有类型的网页 API 读取固定的 Serving 数据代；计算复用纯领域函数；写操作走受控命令。按钮不能仅演示点击效果。
- 每个 Streamlit 单元只有在对应真实使用路径、数据及操作经验证后才记录替代和回退并停用。新平台不再向 Streamlit 增加产品功能。
- 标记「完成」须同时有代码、相关行为验证和发布状态；本地候选不等同于生产可用。

### 本地集成列车（2026-09-27）

`cdx/20260927-web-platform-integration` 以盯盘旧通知候选 `c1ff3a4e` 为基线，先使用两父合并提交整合已审查的选股副本领域层候选 `f7daa707`，再合入已审查的通达信纯函数求值器 `0b471b31`。前一次合并冲突只发生在生成的 OpenAPI 与 TypeScript 合同；两份文件已从合并后的 FastAPI/Pydantic 路由重生，保留选股运行、公式解析和盯盘时间线接口。求值器合并只新增领域代码、聚焦测试与边界文档，不更改网页合同。

本地证据：第一次合并后 Python 3.13.12 聚焦 API/选股领域测试 287 项通过，前端 `check` 102 项通过，`build` 与 `verify:dist` 通过；合成 Serving 数据代下，桌面与 390px 的选股和盯盘 Chromium 路径 4 项通过，均无跳过。浏览器首次在 macOS 沙箱内因 Chromium Mach port 权限无法启动，在授权的本地环境重跑通过。第二次合并只新增 Python 求值领域文件、测试和文档；解析器、求值器、网页选股及 OpenAPI 快照聚焦测试 97 项与 Ruff 均通过，网页源码和合同未变，前端及浏览器结果仍有效。
