# 实验过拟合检查：PSR 与最短观察期计算核心

本片按原型实验记录与 v2 C8.3 补齐统计计算的第一段。任务定级为普通：只新增离线纯函数和类型，不读写登记库、不接任务、Serving、Web 或生产数据。主要风险是把年化夏普与单期夏普混用、把偏峰度口径混用，或把小样本近似值当成可信结论。

## 输入与公式

- 输入是**同一观察频率下的单期**已观测 Sharpe `SR`、比较门槛 `SR*`、偏度、Pearson 峰度（正态为 3）和独立观察数 `n`。调用者必须已完成无未来数据、收益与成本口径的检查；本片不从原始收益推断这些事实。模型拒绝非有限数、布尔伪装的数值、`n < 30`、不可能的偏峰度组合及非正的估计方差因子。年化值不得传入，函数名/文档明确这个单位。
- 采用 Bailey 与 López de Prado 论文附录的 `V = 1 − skew·SR + (kurtosis − 1)·SR²/4`，`PSR = Φ((SR − SR*)√(n − 1)/√V)`。返回 `[0,1]` 内的概率，门槛相等时为 `0.5`。不把概率写成“赢面”或自动晋级判断。
- 最短观察期对明确的 `0.5 < confidence < 1` 采用 `1 + V·[Φ⁻¹(confidence)/(SR − SR*)]²`。当 `SR <= SR*` 时没有可由延长相同表现记录得到的有限观察期，返回显式“不可达”状态；当公式结果小于 30 时仍保留公式估值，并把可报告的最小观察数设为 30，避免小样本近似被直接使用。整数观察数向上取整，不向下修饰结果。
- 使用标准库 `statistics.NormalDist`，不引入统计依赖；计算是确定性的，接口以不可变 Pydantic 模型返回输入口径和结果。

## 验收

1. 论文附录 A.3 的月度样例：`SR=2/√12`、`SR*=1/√12`、偏度 `−0.72`、Pearson 峰度 `5.78`、目标概率 `0.95`，最短期接近 `59.895` 个月；整数最低值 60。附录代码把 `prob` 写成 `0.9521`，与文中 95% 和 59.895 的组合不符，验收以公式和文中 95% 为准。正态样本下的 PSR/MinTRL 和门槛相等 `PSR=0.5` 有独立计算对照。
2. 拒绝年化/单期无法在类型层自动辨认的混用：API 字段、文档和测试明确单期口径；拒绝 NaN/Inf、无效峰度、零/负估计方差、小样本、无效置信度；`SR <= SR*` 的最短期不产生虚假有限数字。
3. 实现局限在 `rquant.overfit` 纯领域模块，保留现有 BH 校正与实验登记不动；聚焦测试、Ruff 和最终候选一次独立审查通过。本片完成后仍需 DSR、CSCV/PBO、真实收益与试验次数来源、研究产物、Serving 与 React，实验页不得将计算占位称为上线。

公式依据：[The Sharpe Ratio Efficient Frontier，附录 A.3](https://www.davidhbailey.com/dhbpapers/sharpe-frontier.pdf)。
