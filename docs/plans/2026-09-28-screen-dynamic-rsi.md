# 只读副本选股的自定义 RSI 周期

对应 C4.1：当筛选数据来自核验过的只读副本时，RSI 超买/超卖可以选 2–60 日周期和 0–30 日偏移；旧 Serving 与池子编辑仍只展示已落盘的 6/14 日。原型的默认 14 日阈值保持，页面用简短中文说明当前可选范围。此片不改变生产任务、不读真实凭据、不写主库。

**分级：普通任务。** 它改变选股可见结果并跨离线投影、API 和 React，但只在未发布的只读副本模式下启用，不涉及权限、生产数据迁移或生产契约。验收以真实计算和来源一致性为主。

## 核心判断

现有 `rquant.indicator.technical` 用 `ta.momentum.RSIIndicator` 对单股升序前复权收盘价从历史起点递推：上涨/下跌幅分别以 `alpha=1/period, adjust=False` 平滑，累计条数不足周期时未知。6/14 日结果不能推导任意新周期；只取最近 `period + offset` 根也会错误重置平滑初值。选股请求不能为每个周期扫描约 10 GB 副本的全部历史。

## 实现方向与边界

1. 离线进程从 `VerifiedReplicaScreenSource` 固定的一代只读副本顺序读取 `daily_bar.close`、`adj_factor.adj_factor`、证券和日期；严格验证一股一日、正有限价格/因子、交易日历覆盖及数据代读前读后未变化。以 `close × adj_factor` 作统一比例的前复权序列，按现有 `RSIIndicator` 口径从每股首条有效日递推 2–60 日的状态；分红除权后的统一分母不会改变 RSI 比值。异常证券或日期输出未知，不能补造收盘价或把缺值当 0。
2. 仅封存网页可选最近 30 个已收盘开市日及其 0–30 日偏移所需的最多 60 个交易日结果。投影包含每股每日每周期的真实 RSI 或显式未知，写入独立、只读、带索引的原子数据代；产物元数据绑定输入副本身份、覆盖日期、计算口径版本及内容摘要。旧代、半成品、源副本换代或投影不完整时不提供自定义周期；原有 6/14 日选项照常可用。
3. 选股请求只按当前副本身份打开相同来源的已封存投影，按证券与有限日期、周期索引读取，禁止原始字段拼 SQL；最多 8,000 只股票、59 个周期、30 日偏移，沿用现有条件数/宽表预算。请求前后核对投影和副本未换代；缺某股某日或未知值保持未知，不算未命中。比较和区间积木也只在投影可用时接受该自定义 RSI 字段。
4. 后端目录只在投影就绪且身份匹配时宣告 2–60 日周期；严格校验 `RSI{period}[{offset}]` 和阈值。React 的周期输入、偏移与提示跟服务端目录一致，加载、换代、不可用和 390px 布局均有明确状态；不暴露文件名、数据代哈希或服务内部标识。

## 验收

- 用多股票、不同上市日期、停牌无行、复权因子变化的合成历史，与现有 `RSIIndicator` 对 2/6/14/60 日和偏移 0/30 的完整历史结果逐项比较；周期不足及坏行保持未知。测试必须能抓到“只用最近窗口重算”和“其他股票历史串进本股”两类错误。
- 投影生成中失败无新指针；源副本换代、投影篡改/缺行、超预算、非法周期/偏移均拒绝自定义项。后端 API 与页面有真实筛选行为，而不是只开放输入框。
- 本片运行聚焦 Python、Web 与桌面/390px 浏览器验证，并由独立审查者在最终候选做一次范围内审查。正式约 10 GB 副本的耗时、内存与服务权限需另行实测，未通过前不标记上线。
