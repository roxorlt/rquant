# 价格提醒规则：同代只读发布

接续 [规则事务权威](2026-09-28-price-alert-rule-authority.md)与[受信命令](2026-09-29-price-alert-command-admission.md)。本片只把已激活的 PageControl 价格规则以有界、可核验的状态与事实发布到一份 Serving 数据代，供后续网页配置页和评估器分别读取；不开放写 API、不运行评估、不推送。

**分级：高风险。** 把其他用户的规则泄给页面，或把已脱离名单的规则当成正在监控，都会造成错误决策或错发。

## 冻结边界与失败模型

- **权威与信任边界**：PageControl SQLite 是唯一规则权威；Serving 只能在现有固定只读、无 sidecar 的 PageControl 审计快照中读取，且规则与 `manual_watchlist` 必须来自**同一个已固定的 SQLite 读事务**。不得回连主库、扫描可变表或为缺表自动建表。规则激活 marker 与 schema 都缺时发布明确的“来源未启用”；两者都在且完全一致时，即使零行也发布可信零；只缺其一、版本不符、行损坏或超过上限均标记规则来源不可用，下一代不得携带上一代规则事实。若共享快照在读中换代、整代无法安全发布，既有代也只能在其有限新鲜期内使用，超期不得保留旧绿灯。
- **事实与作用范围**：按 `(owner_id, rule_id)` 排序发布所有当前 head，包括删除墓碑和单调版本；规则名、级别、比较方向、阈值、时段、启用意愿、股票、名单版本与更新时间均有类型且有界。`enabled=true` 只表示用户意愿，不等于可触发；后续读取者只有在同一数据代的手动名单状态可信、同 owner/股票/版本成员仍有效且评估时刻未过期时才能视为作用范围有效。失配规则仍保留供配置页解释和 CAS 修改，但绝不进入评估范围。任何用户查询必须按已认证 owner 过滤；本片不提供对外查询入口。
- **代际身份**：规则状态行记录激活时间、总行数和内容摘要；事实行、状态行与已有名单投影均绑定同一 Serving generation。发布与读取同时校验唯一键、摘要、行数、时间不晚于生成时刻、字段边界和来源表契约。旧 Serving 代没有规则表时视为“来源未发布”，不推断为空规则；新数据代到来前命令回执只能称“已保存，等待同步”。
- **失败路径**：规则写入和发布并发、名单移出/到期/重加、规则启停/删除后旧代仍在、跨 owner 同规则 ID、SQLite 损坏或 sidecar、marker 与表不一致、超大规则集、不可用的旧数据代。规则来源失效不能导致旧 monitor 或现有通知路径接管本片规则；本片不改变它们。生产数据迁移、服务身份与 `systemd/nginx/sudoers` 仍需单独授权。

## 验收

1. 合成 SQLite 的未激活、可信零行、多用户同 ID、启用/禁用、墓碑、旧名单版本、到期/重加和坏行/坏 schema 产生区分清楚的同代结果；容量边界拒绝整份来源，不截断或泄露其他 owner。
2. 在同一固定 PageControl 快照中读取名单与规则；中途替换、WAL/SHM、写入竞态及来源失败均使规则事实不可用，且下一代不能沿用旧事实。构建和读取端均校验状态摘要及 schema，旧代缺规则表安全降级。
3. 直接相关的 Serving/名单/价格规则测试及实际合成数据代读取通过；无价格触发事件或网络推送。
