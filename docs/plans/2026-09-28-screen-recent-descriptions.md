# 选股器最近描述：同一浏览器会话内快速重用

对应原型选股器的自然语言查询历史入口。旧 `nl_screen` 只在 Streamlit 会话中保留最近五条**成功解析的原始描述**，点击后回填输入框；它不恢复已运行结果。本片先在 React 中承接这条实际使用路径，不把它称为跨设备的完整查询记录。

**任务分级：普通。** 只新增浏览器会话内的输入记录和回填交互，改变用户可见行为，不触及共享 API、生产数据或权限。验收以可复现的会话存储、失效和桌面/窄屏行为为准。

## 验收边界

1. 只有当前来源和日期下成功返回、且经现有目录验证的自然语言建议，才把原始描述写入最近记录。含糊、超时、过期响应、来源变化和服务错误不写。相同描述再次成功时移到顶部；最多五条，每条最多 500 字。
2. 记录仅保存于当前标签页的 `sessionStorage`，刷新后仍可见；关闭该会话即失效。只存用户描述，不存条件、结果、来源身份或模型响应。不调用旧全局 `nl_queries.jsonl`，也不承诺跨设备同步。
3. 点击记录只回填描述并清除未应用的过期建议，不自动生成、应用、运行或恢复旧命中数；已在编辑的手工条件和真实结果不被覆盖。输入框获得焦点，键盘可操作。
4. 浏览器禁用存储、旧版或损坏记录时仍可正常生成与手工筛选；有界解析和写入失败不导致页面崩溃。空态不增加解释性长文案；页面标题用「最近描述」，具体语义放悬停提示。
5. 聚焦测试覆盖成功/失败、去重与五条上限、刷新恢复、损坏存储、回填和迟到响应；桌面及 390px 浏览器确认可点击、无横向溢出且没有技术标识正文。

本片不新增后端写入，不把模型预览当成真实运行，也不改变 Streamlit 的迁移门。完整的已执行查询历史、预设保存与跨设备记录留给后续有来源身份及用户边界的独立增量。
