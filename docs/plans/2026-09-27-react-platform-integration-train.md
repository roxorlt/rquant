3. 只运行合并直接影响的 Python API/领域聚焦测试、前端 `check`/构建/产物验证，以及桌面与 390px 的选股和盯盘关键路径。若生成合同或共享路由使结果失效，修复后定向重跑。所有测试 skip/环境限制如实记录。
