# 因子历史冻结来源到检验输入

接续已审查的冻结来源准入 `66270ce7` 和纯结果、预热日期、收益可见性合同。**分级：普通任务。** 本片只新增领域适配器与聚焦测试，消费公开的 `FactorReadLease`，不改变共享快照/正式策略门禁、数据库、Lab、Serving 或页面。主要风险是把未来价格带入 09:25 因子、跨数据代拼接、将事后修订称为真实当时可见，或把未成熟收益写成已知值。验收以本文件及 `2026-09-29-factor-frozen-source-design.md` 为准。

## 冻结输入与输出

- 输入是已通过 `open_factor_snapshot_admission` 的 `(FactorReadLease, FactorSnapshotAdmissionDecision)`、受限 `FactorDefinition`、明确的固定股票代码列表、评价日期、查询日期范围、`holding_sessions` 1/5/10/20 与带时区 `as_of`。不接受“全市场/指数成分”的来源声明；股票池身份由规范排序代码生成摘要，回执固定写 `explicit_fixed_list`。
- 适配器只用租约的三种公开查询读取日线、复权因子和 SSE 日历。每批回执必须同属本次 `snapshot_id/binding_hash/as_of_time/source_mode`；所有日期和股票在请求范围内，重复键或不一致即拒绝。分段查询可覆盖大于单次租约 366 天的范围，每段仍受 100,000 行上限；总输入受纯因子模型的上限约束。
- 输出有类型的封闭来源回执和 `FactorResearchRequest`，并提供将二者与纯 `FactorResearchResult` 成对返回的入口。回执包含冻结身份、`historical_retrospective`、`retrospective_adapter_assumption`、固定池摘要、允许列、面板日与决策日映射、收益窗口与成熟时刻、缺数计数及确定性摘要。后续 Lab 必须把回执与结果一起封存；纯结果自身的 source ID 也绑定同一摘要。页面不得把模拟可见时间说成真实采集时间或把分组价差称为净值。

## 时点和计算合同

1. SSE 日历必须覆盖查询范围的每一个自然日，开市日严格递增，其 `pretrade_date` 指向范围内的上一开市日（首个开市日可指范围外）。评价日必须为开市日；最早评价日之前须有 `max_history_window` 个开市日，使每个计算日 d 都能拿上一开市日 t 的面板。`FactorTimeSeriesInput.trading_days` 从所需首个预热决策日连续到最后评价日；只用 t 日 `daily_bar` 行产生 d 日特征，`first_visible_at=d 09:25 Asia/Shanghai` 是历史回溯假设。缺股票行保留缺观察，列值为空保留缺值，禁止填补。首个 d 无 t 或预热不足时拒绝。
2. 首片只支持日线 `open/high/low/close/vol/amount` 作为定义目录与依赖列；外部行业/市值上下文及缺数据合同的列和相关算子明确拒绝。`adj_factor` 仅用于事后收益，d 日价格与复权因子绝不进入 d 日的因子特征。
3. 每个评价日 d 的收益窗口终点是从 d 起第 h 个 SSE 开市日收盘（h=1 即 d）；收益为 `close_end × adj_end / (open_d × adj_d) - 1`。所有股票同一 d 共用终点与下一 SSE 开市日 09:25 的模拟成熟时刻。若 `as_of` 早于终点，网格填 `window_unfinished`；终点已过但成熟时刻未到，填 `visibility_pending`；到期后才用完整价格/复权事实计算，缺价格、停牌或复权事实按封闭原因缺失，绝不退回未复权收益。评价窗口必须符合纯结果的不重叠合同；不能求出终点和下一开市日时拒绝。
4. 适配器不读取主库、私有 `_conn`、网络或 Web，不创建研究任务，也不把历史回溯提升为正式前瞻证明。`return_price_basis` 采用 `forward_adjusted`，回执写清日开盘至第 h 日收盘和两端复权因子的计算口径，组合结果只称研究诊断。

## 实施与聚焦验收

1. 先写端到端小型冻结 DuckDB 红测，通过实际专属 builder/准入/租约走到适配器及纯结果：3 股、预热、跨周末与两段不重叠评价窗口，手算特征、复权收益、IC/覆盖和稳定摘要。用 d 日价格改动但 t 日面板不变的夹具证明 d 因子不变，收益改变；另一绑定的修订不能混入原回执。
2. 补边界红测：周五终点至周一 09:25 为 pending；日历缺一天、缺下一开市日、错误 `pretrade_date`、缺前驱/预热、未知列/上下文、重复或跨代行、复权缺失/非正、停牌、超限、不重叠失败，以及固定池不能声称全市场。红测到绿测或等价行为证据须可复现。
3. 仅跑直接相关因子/来源/正式 gate 聚焦回归、Ruff、diff、固定清单合同；在本分支重生清单并更新计数。最终候选安排一次独立审查，普通任务最多一次定向修复和复核。真实生产数据规模与资源消耗、Lab/Serving/React 留在后续切片验证，进度台账仍称本地候选。
