# 因子研究页：真实检验结果的交互与文案

**任务分级：普通任务。** 本片在已存在的因子目录页展示经过同代 Serving 核验的单因子检验结果，改变用户可见行为，但不开放写命令。以 CC 可点击原型的因子页为布局和操作目标；原型的随机示例值、`有效/偏弱` 假判词和即时完成提示都不能进入正式页面。运行检验、跟踪、保存/编辑在各自受控命令接通后再启用。

## 页面与数据边界

- 保持当前因子列表、定义详情和归档恢复能力。选中定义时，按因子 ID、版本和内容摘要从**同一 Serving generation**的结果列表找最近一次成功检验；也可切换该定义的最近检验记录。摘要不同的历史记录不能作为当前定义的成绩。换代或选择其他定义立即清除旧图和旧错误；遇 409 刷新数据代后重取，不展示跨代拼接。
- 有可信结果时，右侧依次呈现原型的 IC 统计、1–10 期衰减、IC 时序与有效日相关系数累计和、3/5/10 组累计收益与目标权重换手。NormalIC/RankIC 可切换；统计和曲线始终指向同一条检验任务，组数只切换这条结果确有的组，不在浏览器重算研究指标。需要多选参数和运行任务时，由后续真实提交入口承担。
- 页面不展示服务名、job ID、文件摘要、数据代或原始状态串；必要的来源与完整时刻放在 `Tip` 或详情中。检验区间、股票池口径、调仓期、样本覆盖和结果时间用简短中文说明；“历史回溯研究”只放一处醒目的小标记，解释“未计成交和费用”放提示。累计 IC 写“累计 IC”，提示明确它是**有效日 IC 之和**，不是收益。
- 每个缺失统计显示“—”，悬停/点按可看“有效样本不足”“收益尚未成熟”等具体原因；图表以 `null` 留断点，不连线、不补零。部分覆盖提示“部分日期可计算”，不能叫“有效”。IC 均值、IR、p 等保留适合的精度；收益与换手用百分比，数量加千分位，更新时刻用 `RelativeTime`，完整时刻在提示。筛选因子能力的判断留给用户，不根据原型示例阈值自动贴“有效”。
- 未发布、可信空任务、正在运行、任务失败、历史回执无展示产物、结果超当前发布预算、结果文件校验失败分别有明确状态；提供与状态相符的下一步（刷新、查看任务或重新运行）。核验失败不沿用上一条成功图表。没有受控提交入口时，页面不出现可点的“运行检验”；没有跟踪权威时，不出现可点的“加入因子跟踪”。

## 交互与验收

1. 复用 `@/charts/EChart`、`@/charts/tokens`、`@/table/DataTable`、`@/api` 与 `@/ui`；页面不直连 ECharts/antd/TanStack 或研究文件。IC 两层时间轴与其他三块图表的曲线、图例、键盘焦点和触屏提示均可用；颜色从设计变量读取，正负和收益红绿遵守既有规则。桌面双栏与 390px 单栏按内容顺序布局，按钮与图表触摸区域可操作，无横向溢出。
2. 合成 Serving 夹具验证有结果、无结果、部分缺数、旧版定义、换代、API 错误和窄屏。核对页面正文内部标识检查、生成 TS 合同、前端聚焦测试、构建/产物一致性，以及桌面和 390px 的选因子→选检验→切 IC/分组→换代路径。正式数据代和浏览器真实用户验收仍是迁移前置条件。
