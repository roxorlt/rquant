# 因子定义的不可变版本登记

对齐 v2 C3.1 的 `save_factor_definition` / `archive_factor`。本片只完成因子领域的持久版本权威，后续才由 PageControl 命令、Serving 和 React 接线。**分级：高风险。** 定义版本一旦被检验任务引用，错误覆盖或并发改写会破坏结果复现；因此先冻结下面的失败模型。本片不改现有策略 `DefinitionRegistry`、PageControl 命令协议或生产数据库，不部署迁移，也不声称因子页按钮可用。新登记使用调用方指定的独立 SQLite 路径，避免把因子研究状态耦合到生产 DuckDB 或策略执行定义。

## 冻结失败模型

- **资产与边界**：资产是每个 `(factor_id, version)` 的完整 `FactorDefinition`、内容摘要、当前 head/归档状态、命令回执。信任边界为未来受控命令消费者 → 因子登记；消费者身份和权限由后续 PageControl 入口核验，登记本身只接受已验证的有类型请求。
- **失败路径**：两个保存并发领取同一下一版本；同一命令 ID 带不同内容重放；保存事务中断后只有 head 或只有版本；归档与保存竞态；读者把已损坏 JSON 或摘要当成合法定义；旧版本被静默改写或删除。
- **不变量**：一条 SQLite 写事务同时完成命令去重、版本追加和 head/归档更新；首先查命令 ID 与请求摘要，已完成的同请求重放直接返回逐字相同的原回执，不能再用已推进的 head 做 CAS；异载荷重放拒绝。新命令首次保存版本为 1，之后严格递增，CAS 比对上一 head 的版本与摘要。旧版本不可变且按精确版本可读；归档只隐藏当前列表，不删除历史，不改变已存在版本。每个已分配版本从 1 到 head.version 必须连续且可验证，版本表不能有孤儿 ID；列表、head 和精确读取都核对这一范围，旧版本缺失属完整性错误而非“未找到”。任何存储不一致在读取时明确拒绝，不回退到旧值伪装成功。
- **排除与阻断**：本片没有在线身份、共享 Serving 数据代、真实数据集可用性或模型代码执行，不补 PageControl/网页接口；缺稳定命令身份、期望 head 或定义校验失败时拒绝写入。生产文件创建、迁移和发布必须在后续单独批准的流程完成。

## 领域合同

1. 新增专属 `FactorDefinitionRegistry`，构造时接受明确文件路径；独立表保存不可变版本、单个 head/归档标记与命令回执。对外 API 使用 Pydantic 请求/回执，函数签名有类型。保存者传 `command_id`、完整已验证 `FactorDefinition` 和可空 `expected_head`；请求的 `definition.version` 必须等于下一版本，不能由客户端覆盖旧版本。首次创建需要空预期；后续保存需要精确旧版本及摘要。因子 ID 由模型校验。
2. 保存使用 `BEGIN IMMEDIATE` 和数据库唯一约束处理并发；在同一事务内**先**按命令 ID 核对请求摘要与原回执，只有全新命令才检查 head CAS 并写入。另一个命令抢先推进 head 后旧 CAS 冲突，但先前成功的命令在 head 又推进或归档后重试仍返回原回执。版本、head、命令回执任一步失败须整笔回滚。归档也用相同命令去重顺序、精确 head CAS 与独立归档事件/状态；历史版本仍可按版本与摘要读取。任何新版本的保存重新激活 head，不能复用被归档的旧版本号。
3. 定义以规范 JSON 和 SHA-256 固定内容身份；读取列表、head、精确版本时都重验模型、摘要与 1…head.version 的连续历史，返回完整定义和状态。缺任一已分配旧版、缺 head 但仍有版本或版本号跳跃都拒绝整次读取；未分配的未来版本才返回“未找到”。列表有上限与稳定排序；只读接口不创建或修复文件。以后 Serving 只能从此登记读取已核验版本，Lab 必须记录精确版本及摘要。

## 红测与完成条件

用临时 SQLite 路径先复现首次保存、版本 2 CAS、不同载荷重放、并发抢同一 head、保存/归档竞态和重启后精确版本读取。特别验证命令 A 保存 v1 成功、命令 B 保存 v2 或归档后，原样重试 A 仍拿到完全相同的原回执，改动 A 的载荷则冲突；在版本行已写而 head/回执提交前注入 SQLite 故障，重启后不得有孤儿版本或半更新 head，原命令可安全重试。注入坏 JSON/摘要、head 指向缺失版本，以及 head 完好但非 head 旧版被删除，列表/head/精确读取都须拒绝完整性错误，不把损坏状态当空库或“未找到”。旧版本在新增和归档后仍可读，当前列表按归档过滤。仅跑直接相关因子定义和登记测试、Ruff、diff；固定清单在最终集成时统一重生。高风险 SPEC 在实现前审一次，最终候选再独立审一次；阻断修复最多三轮，范围仅本合同。
