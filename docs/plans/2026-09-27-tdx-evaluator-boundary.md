# 通达信公式纯函数求值边界

> 2026-09-27。承接已审查的 `tdx-v1` 解析器；只实现 C4.5 的领域求值层。网页预览、保存和日常池子运行仍属后续增量。

## 分级、目标与验收

**高风险**：公式来自不可信文本；数值缺失、历史不全或资源失控会造成错误选股或拖垮网页。此阶段把已解析且受静态检查的公式，应用于调用者提供的**单一来源、按股票和日期排序的历史行情**，返回每只股票在指定日期的三态结果（命中、不命中、未知）及缺失原因。不能把未知当成未命中，更不能使 `NOT` 把未知翻成命中。

已解析公式不能作为可伪造的外部输入直接执行；求值入口应从原始文本重新解析并验证，或接受仅由解析器内部创建且不可伪造的受信计划。求值器不打开数据库、网络或文件，不写状态；网页和数据源接入另行审查。

验收：全部 `tdx-v1` 白名单函数和算术/比较/布尔运算有固定手算样例；常见 MA/EMA/SMA 等与现有 MyTT 的固定参考值核对；分股票计算、日期边界、缺值传播、零除、首日/短历史、完整历史标记、输入预算及恶意公式均有聚焦行为证据。已有解析 API 与其他筛选规则不回退。

## 冻结的威胁与失败模型

- **资产及信任边界**：调用者提供的历史行、股票标识、交易日和决策时点，以及解析器保证的 AST/窗口约束。原始公式和行情输入均不可信；调用者负责证明历史来自同一经核验数据代、可见时刻及覆盖状态。领域求值器须再检查形状、排序、重复键、数值类型、非有限值和预算。
- **失败路径**：伪造 AST 绕开静态限制；`REF` 或窗口读取未来行；股票间串行污染；缺失值经比较或 `NOT` 变成命中；EMA/SMA/BARSLAST 在被截断的历史上给出貌似精确的结果；零除或溢出生成无限值；大量行乘大量 AST 中间向量耗尽内存。
- **不变量**：只计算指定日期及之前的事实；各股票隔离；有窗口/前一日需求但输入不够时给未知或明确拒绝；递归布尔逻辑保持未知；非有限运算结果是未知；`EMA`、`SMA`、`BARSLAST` 只有调用者明确标记自上市以来完整历史时才给确定值；公式超出行数、股票数、历史跨度或中间向量预算时显式拒绝，不截断。计算只使用白名单纯函数，不执行 Python/SQL 表达式字符串。
- **排除**：读取真实或生产副本、API/React、任务调度、公式池保存、主库/生产配置、部署与 Streamlit 停服。纯函数通过不代表 C4.5 完成。

## 实施约束

1. 使用现有 `parse_formula` 的语义与 `TranslationPlan` 推导所需字段和回看；不要另写不一致的公式语法。定义类型化的历史输入/结果合同，明确日期、完整历史标记与未知原因。构造/验证由求值边界负责，调用者不能任意传入已验证结论。
2. 按单个股票的时间序列执行，字段仅 `CLOSE/OPEN/HIGH/LOW/VOL/AMOUNT`。市场行可批量传入，但求值器不得混用股票；输出只取请求的决策日，不把中间序列暴露为已验证信号。
3. `MA`、`REF`、`HHV/LLV`、`COUNT/SUM/EVERY/EXIST`、`CROSS` 用有足够历史的因果窗口；`EMA/SMA/BARSLAST` 使用明确且可复核的初始化语义，只在完整历史下求确定值。每个函数与运算符都给出空值规则，布尔值用三态而非普通 `bool(NaN)`。
4. 入口对字节、AST、股票、每股日数、总行数以及行数 × 活跃中间值施加有界预算。可分批计算以降低峰值；不能靠默默丢弃股票、日期或子表达式满足预算。限制所依赖的原始行情数据总量，禁止访问未来日期。
5. 先写聚焦红测，再实现；跑 TDX parser/evaluator、受影响的 screen 和 web parser 测试，Ruff 与 diff 检查。形成最终候选后安排一次独立高风险审查；修复按根 `AGENTS.md` 的轮次上限。

## 后续接入门禁

公式预览需要 C4.1 已核验的历史副本读取与真实规模资源测量；调用者需证明同一数据代、决策时点与完整性。保存需要版本化 PageControl 命令重新解析、固定语法版本和 AST 哈希。此分支不得把纯函数求值包装成已可点击、已保存或已上线的功能。
