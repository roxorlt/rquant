# 公式运行绑定逐日名单与历史投影

## 范围

把已实现的逐日名单归档与有界历史公式求值连接为一个**离线**运行入口。运行结果的范围固定写为“所选日期已采集的 A 股名单”，并同时携带名单归档摘要和行情投影身份；不使用累计 `stock_basic` 代替名单，也不在 Web 请求内遍历市场。本切片不接任务队列、Serving、React 或池子保存。

任务分级：高风险。跨两个独立来源的日期、上市日或数据代混用会产生错误的命中和分母；万级历史计算仍有资源上限风险。

## 验收标准

1. 新离线入口接收显式的名单归档根、历史投影根、目标开市日期、公式、执行时刻和两个期望身份。先读取同日期名单与投影目录；名单超过 10,000 只整体拒绝，不截断。执行时刻须不早于名单实际完成时刻和投影来源更新时间，且满足已有收盘日线门槛；这表示事后研究运行时间，不冒充目标日 17:00 当时可见的资料。
2. **以归档名单为唯一分母**。投影目录没有该股票，或两边上市日期不一致，该股票记“未知”并说明来源缺口，不默默排除，也不当成未命中。名单中的 P 状态保留；无所选日行情时记“未知”。投影多出的旧/退市股票不进入本次分母。公式真值计算沿用已审过的纯求值器和单股历史校验，不复制指标语义。
3. 返回有类型摘要：日期、范围、两来源身份与观察时间、名单总数、L/P 数、命中/未命中/未知数、未知原因计数、稳定排序的命中代码。总数必须守恒。全局公式错误、日期不符、来源损坏/换代、超时与容量超限整次失败，不交付部分结果；单股可归因的历史/计算预算只记“未知”。结束前再次核对**两个**来源身份。
4. 先用合成不可变文件写红测，再实现；覆盖已归档 3 股手算、P 缺行情、投影缺代码、上市日冲突、目录额外旧股、不同日期、未来时刻/来源、两边换代、容量/超时、未知与计数。复用现有目录运行器逻辑，避免重复计算引擎。相关 Python 聚焦测试、Ruff、差异检查通过，最终候选一次独立审查。

## 冻结的失败模型

- 资产：名单分母、历史行情、来源身份、公式结果。边界：两个各自核验的不可变只读代与离线纯编排层。
- 失败路径：内层连接取交集漏股票、累计旧目录扩大分母、名单日期不符、归档更正或投影换代期间拼接两个版本、执行时刻早于数据可用、异常后交付部分命中。
- 不变量：每个归档代码恰好有一个命中/未命中/未知决定；所有决定来自同一对期望代；任何整体完整性或容量错误只返回失败。旧日期没有归档即不可运行，不推断为零股票。
- 排除项：真实 Tushare/Linux 权限负载验收、正式任务和结果产物、网页交互、池子保存、生产部署与 Streamlit 停用。
