# 数据中心：可查的数据目录与字段字典

> 对应 v2 计划 C1.1 的第一条纵向路径。数据样例依赖后续只读产物发布；此切片不从网页 API 直连主库或只读副本获取临时样例。

## 用户路径与验收

打开「数据中心」后，用户可按分类或关键词找到已有数据集，看到中文用途、来源、更新时点、可见时刻、主键和字段定义。点选数据集时，字段表可按名称查找；类型和已知单位清楚显示。无数据集、目录构建失败、字段没有人工说明时必须明确提示，不能伪造样例或把内部服务代号当作正文文案。手机宽度可从分类切到详情，键盘可操作。

目录来自仓库真实 `DATASET_CONTRACTS` 和本地构建时的 schema；人为维护的中文数据集说明与字段说明须在 `src/rquant/data_catalog/` 统一放置。脚本在构建时输出版本化静态 JSON，网页 API 只读此 JSON，React 只渲染接口类型。新增加契约但忘记说明时聚焦检查失败。样例行暂显示「样例数据尚未发布」；未来用研究面的 `dataset_samples` 产物，不读取线上任意表前 20 行冒充可见样例。

## 设计边界

- 数据目录是文档视图，标识符如字段名/数据集 ID 可在专门的字段表或悬停提示中出现；页面导航、状态和操作文案仍用简短中文。
- 在生成期验证契约、schema 与描述对齐；API 运行期不得导入 `storage`、`data_contracts` 或直接打开数据库。
- 没有该数据集的本地 schema 时如实展示「字段结构待发布」，不要根据猜测补字段。
- 保留现有前端壳、API envelope、OpenAPI→TypeScript 链路、只读 Serving 边界。

## 聚焦验证

用小型合成契约和 schema 验证目录生成、字段类型/单位、中文说明缺失时失败；现有契约至少各有中文名称和用途。API 对不存在的数据集返回清楚的 404；页面验证检索、详情、空状态与 390 px 布局。只跑相关 Python、前端、浏览器测试及构建门槛，不做生产数据查询或基础设施变更。

## 本切片的交付边界

- 生成命令：`PYTHONPATH=src python scripts/build_data_catalog.py`。它只在内存中应用仓库迁移，输出 `src/rquant/data_catalog/catalog-v1.json`；新增契约、字段或数据源而未维护中文说明时会失败。提交时同步该 JSON 与 OpenAPI、TypeScript 类型、前端 `dist/`。
- 页面已有 23 份契约的目录与字段字典。`更新要求`是契约的新鲜度要求，不能当成具体采集任务的计划时刻；单位没有统一源端口径时不猜测，显示「—」，说明中标明沿用数据源口径。
- 数据覆盖率、质量问题、可见样例与补数操作属于 C1 的后续纵向路径。本切片所有样例明确显示「样例数据尚未发布」，不读生产表拼装展示数据。
