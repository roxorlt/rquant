## 归属、风险与边界

本片为 C1.2 普通任务：只从已固定的只读副本或具名湖分区提取有界统计，复用现有报告、API 与数据中心。它不写源数据，不改变权限、任务恢复、调度或生产合同。

原生执行身份为 `/root/research_sdk_review`，本次角色是 implementer，父任务 `/root`。实际工作树为 `/Users/roxor/brain/30-projects/rQuant/.worktrees/cdx-factor-neutralization-react`，分支 `cdx/20261005-data-audit-datasets`，基准 `df1efee7dec0a4e4e109d10604b435e1186ae7b8`。开始时 tracked/untracked 均干净，复用归属见 `data/verification/data-audit-datasets-20261005/worktree-reuse.json`。不委派、不联网、不读 `.env`、凭据或生产。

主要风险是把有限的日期记录当成完整行情，或把零问题当成健康。目录中 24 个合同有不同日期、可见时刻、频率和历史保留范围；合同未声明权威证券全集或完整分钟网格。报告必须保留这些缺因，不从已有行反推应有行。

## 方案

保留日线 v1 报告模型、摘要和原三条规则。新增 v2 报告，在原日线结果上附加全部目录数据集的统计、合同摘要、规则版本和明确的观察时刻。旧产物继续可读。一次任务仍固定同一源；新产物通过原发布函数保存，Serving 只读小投影，原 API 在一次借用中读同代结果。

任务的可见性时点固定为所选截止日的下一日 00:00（上海），使原请求重试得到稳定产物。实际执行时间保留在任务记录。页面提示说明这个时点；真实只读驱动使用调用方固定的实际读取时刻。

取证器只接收调用方已固定的只读连接。逐合同读取日期行数、可见/待可见行数、更新时间、实际频率、来源和字段空值；不返回原始证券行。纯统计层计算按交易日的记录覆盖、跨月缺口、休市误入行、行数变化和合同允许的延迟。分钟网格、证券全集、当前参考快照的历史范围等缺少权威时，标为“缺少应有范围”；未知可见性标为“未评估”，事件驱动或不保留历史则不套用逐日完整性。

具名湖适配复用现有分区核验器，只访问明确清单，并将统计绑定清单摘要。清单不能证明整个湖完整。来源不存在、合同列缺失、不适用和未评估是不同状态。空数据不能产生健康结论。

## 验收

- 每次报告包含全部 24 个目录合同，源标识、规则版本、合同摘要和观察时刻一致。
- 日线、分钟/竞价、参考与事件类使用各自合同；覆盖为日期存在性时明确标注，完整证券/分钟范围缺失不会显示健康。
- 独立小例核对跨月缺口、休市、空值、迟到和未完成日；日线 v1 摘要与三条规则保持兼容。
- API 保留同代约束；数据中心桌面与 390px 可用，键盘可读提示，加载/空态/错误清楚，新任务失败仍可查看上次成功。
- 提供固定输入的真实只读取证驱动与独立参考；只输出统计/元数据，源不变，私有临时目录和进程已回收。
