# 因子检验：逐日完整横截面的流式统计

**目标：** 将已经计算的逐日因子值与完成收益按完整股票池配对，流式产生 IC、3/5/10 组收益、累计收益和换手。只保留当前横截面、上一期成员及有界逐日诊断，不保存全区间逐股样本。

**任务分级：普通任务。** 本片是离线纯计算，新增独立合同，不改权限、任务账本、生产数据或已冻结的研究产物。主要风险是漏股后静默缩池、时间错配、跨缺数期间虚构累计收益和换手；用聚焦行为证据及一次最终独立审查收敛。

冻结基准为本地集成提交 `189712ff6bf8684630a74deeb50f3ff36ede1ac2`。允许写入 `src/rquant/factor/daily_stream.py` 和 `tests/unit/test_factor_daily_stream.py`；如确需提取同包纯数值助手，先向 orchestrator 提供具体重复点及最小受影响范围。本片不提高既有固定名单适配器、`FactorTimeSeriesInput` 或快照读取器的容量上限。

## 层次与范围

- 证券来源准备负责事实完整性，`universe.py` 负责逐日选择，公式计算负责因子值，本片只负责完整横截面的配对、统计和跨期聚合。公式滚动计算、来源按日读取、IC 衰减多期限事实、网页提交及真实副本负载验证继续按接续计划实施。
- 输入是一次性可迭代的不可变 Pydantic 单日批次。固定请求包含因子定义、方向（沿定义）、精确且升序的评价日程、`as_of` 和有类型的来源身份；每批包括所选股票池、对应日期和来源摘要、决策/收益窗口、因子值与收益事实。来源摘要是调用方的受信绑定，不是外部供应方真实全市场覆盖证明。
- 输入可用 `FactorUniverseResult` 绑定逐日股票池，但须再检查所选代码唯一/格式有效、选择与日期一致、计数一致及摘要格式；不能仅依赖输出模型的类型注解。本片不声称可从结果摘要反推并独立核验原始证券事实。
- 现有 `FactorTimeSeriesValue`、`FactorForwardReturn` 和 `DailyFactorResult` 可复用；所有新跨层模型严格、冻结、拒绝额外字段。源批次最多 7,000 个股票，每股必须恰好一个因子值和一个收益事实，缺失是显式 reason，不能漏行或取交集。可信空股票池是无样本日，不能当作缺来源。

## 可验证合同

1. 日程最多 1,024 日，批次顺序和数量与请求精确一致。缺日、多日、重复、乱序、不同选择或不同来源模式、日期错配、跨池值、重复键、容量超限都拒绝整次最终结果。迭代器异常不转换成成功或已完成。输入不整体 `list()`/`tuple()`，不二次迭代；最终结果只有所有日通过后才返回。
2. 股票代码为六位数字 SH/SZ/BJ 且排序规范。每批决策时刻属于该上海民用日且不晚于 `as_of`；因子结果日期/代码吻合，现值的 `latest_visible_at` 不晚于决策时刻，缺值状态不得携带可用时刻。收益日期/代码/决策与共同结束时刻精确吻合，窗口结束在决策之后；现值须结束且首次可用不晚于 `as_of`，缺值的 `window_unfinished` / `visibility_pending` 与时间相符。常数因子的 `latest_visible_at=None` 沿既有合同按决策时刻配对。相邻收益窗口不得重叠，沿 1/5/10/20 持有期的非重叠评价日程；明确记录持有期，批次摘要包含窗口事实，纯核心不猜测交易日日历。
3. 配对只取因子值与收益都存在的股票，输出 expected/valid、因子与收益分别按原因缺失的计数。横截面存在缺失时明确为部分可用，0/1 对样本、常数和零方差保持既有 IC 原因；不填 0 或伪造统计。NormalIC/RankIC 与现有 `evaluate_factor` 一致，方向及相同值的股票代码排序一致。
4. 全日配对完成后计算 3/5/10 组，复用既有同包数值/排序/分组助手。单期等权收益、好组减差组、多空累计差值（不是可交易净值）及 `0.5*sum(abs(w_new-w_old))` 换手与现有完整样本计算相同；首次换手为空。不得按股票分块各算 IC 或分组再平均。
5. 每种组数独立处理有效样本不足或不完整样本。配对不完整的日仍可提供带部分可用标记的当期分组观察，但累计收益从首次缺样本日起及之后保持空值，不能跨缺失窗口连出完整曲线；某组数样本不足时也从该日起使该组数的累计持续为空。发生缺样本或分组样本不足时使该组数的上一期持仓失效，下一次可分组日换手为空。未发生缺口的完整日继续确定性复利。分组数不足不能阻断仍可计算的 IC 或其他组数。
6. 最终仅保留逐日轻量诊断（最多 1,024 日）、IC 汇总及有序输入批次摘要。沿请求来源/定义身份和规范单日事实生成确定性 digest；同日输入顺序不同不改结果/摘要，股票池、事实、窗口、定义、方向或来源改变必须改变。全期原始因子/收益批次不得留在结果或闭包中。

## 实施与证据

- 先写一次性迭代、已知正/负 IC、方向、ties、3/5/10 组完整样本与既有批量结果等价，以及两日成员变化的换手/复利用例。
- 覆盖显式缺因子、缺收益、无样本/可信空池、时间未完成、缺来源/日程、漏行、额外行、重复、错日期/截止时刻和共同窗口；覆盖缺样本后累计及下一期换手为空。
- 用生成器提供 7,000 股单日及多个日期，验证不会触发旧 500 股/100,000 全期点限制且不会保留过去源批次。做一次有界合成内存观察，记录真实峰值与样本尺寸；该结果不代表真实 10 GB 副本负载通过。
- 聚焦运行新增测试、原 IC/portfolio/summary 直接依赖回归，以及 Ruff、格式和 diff-check；不自动运行全仓测试。最终候选一次独立终审，普通任务最多一次定向修复和复核。
- orchestrator 负责本地集成、测试清单及进度。离线 Python 环境、合成临时目录、禁用 dotenv/通知；无网络、真实数据库、生产进程或发布操作。

本片完成只代表完整逐日样本的流式统计能力；原型「运行检验」、多期限 IC 衰减、公式流式执行及正式来源链路仍须真实接通和验收。
