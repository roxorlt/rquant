# 90 日成交量分布来源计划

目标：完成 v2 C3.1 的 VP 内置字段，接入因子检验、结果和持续跟踪。
本片在竞价来源验收合入后实施，沿用该因子实现工作树。

## 范围

普通任务：读取历史行情并计算研究字段，不修改生产数据、鉴权、账本或发布流程。
风险是复权、成交量单位、日期窗口和旧算法变化。由原生 implementer 实现，完整候选做一次独立审查。

本 goal 不限制行政执行时长或修复次数。验收只处理当前范围的实际问题；不重复已有效的证明。
实现开始时记录实际分支、基准提交和修改来源。本文件不授权覆盖其他人的修改。

## 计算口径

- 复用 `volume_profile.py` 的 `calculate_volume_profile_outcome`。必要时只抽出共享纯计算核；原生产接口继续调用同一计算，用原用例和等价输入证明不变。
- 因子决策日 09:25 使用前一完整 SSE 面板。VP 的 reference_date 为该面板日；原窗口取严格早于 reference_date 的最近 90 个实际日线日期，不加入当日或未来分钟。
- 保留原 `1min`、`bin_pct=0.005` 默认口径，以及 POC 并列和连续价值区规则。不得换成日线近似筹码或新版实验引擎的另一套算法。
- 参考价、分钟价格、复权因子和可比股数沿原规则。成交额不复权，成交量和价格按同一基准换算；记录实际来源和单位。
- 没有完整 90 日分钟时，保留原可用计算及实际覆盖日期。页面提示明确「已用 X / 90 日」，不能把稀疏分钟称作完整覆盖。
- 缺分钟、缺参考价、缺复权、无效或非有限数据保留原诊断。空值不补零；不能借未来数据补窗口。

## 字段

复用现有 `VolumeProfile` 数值，另加 `vp90_` 前缀区分口径。

| 原字段 | 中文标签 | 单位 |
|---|---|---|
| vwap | 90日成交均价 | 元 |
| poc_price | 90日成交峰值价 | 元 |
| value_area_low / value_area_high | 90日价值区下沿 / 上沿 | 元 |
| concentration_top5_pct | 90日成交集中度 | 百分比原值 |
| below_reference_amount_pct / above_reference_amount_pct | 参考价下方 / 上方成交额占比 | 百分比原值 |
| below_reference_volume_pct / above_reference_volume_pct | 参考价下方 / 上方成交量占比 | 百分比原值 |
| total_vol / total_amount | 90日可比成交量 / 原始成交额 | 股 / 元 |

90 日指日期窗口，价格是分钟成交近似。定义和提示须说明这两点。

## 接线与验收

1. 先冻结原计算的直接红测与等价输入，包括除权、缺因子、零量、双峰和并列。
2. 来源准备使用已核验副本及具名分钟分区。保存各自实际身份、摘要和目录状态；不扫通配文件，不提升降级研究湖为生产权威。
3. 按股票和日期有界处理，复用同日事实与窗口，避免为每个字段重复读分钟。实际输入超过额度时明确拒绝，不静默缩小股票域。
4. 新来源仅显式启用。旧 v1–v6 缺省字节保持；保留 500 码查询、最多 50 个股票字段、另 2 个市场字段、7,000 码、1,024 日和 2 MiB 解码上限。大清单使用已有内容地址引用。
5. 接能力目录、可信任务、结果及因果前缀。证明首次加追加与整段一致，重复不累计，取消保留历史；最宽合法 spec 可入账并读回。
6. 因子页支持中文搜索、插入、单位、原值示例、覆盖及缺因。说明放 hover/focus/tap 提示；验证键盘和 390px。
7. 冻结完整候选后一次独立审查。root 用实际具名原件与独立参考核对数值、日期、复权、缺因、资源收尾，再合入本地集成。
