# 实验过拟合检查：CSCV/PBO 纯计算核心

类别：普通任务。基于已审查的 PSR/DSR 核心 `d0b59b3a`，只增加同步试验收益矩阵的离线 CSCV/PBO 计算和聚焦测试；不读写实验登记、研究产物、Serving、网页或生产数据。风险是把不完整或不对齐的试验族算成可信的过拟合概率，或让组合数失控。

## 选择与职责

比较过三种路径：由实验汇总指标反推 PBO、网页请求时临时重跑试验、以及从完整同频收益矩阵离线精确枚举 CSCV。前两种缺逐期 OOS 排名，且网页热路径无资源界限；采用第三种。调用方必须先核验假设族完整、每个候选共享时间轴与收益/成本口径、所有收益在决策时点之后、样本外未被反复解封。纯核心只验证可由输入本身证明的结构，不能代替这些来源检查。

输入为不可变 Pydantic 模型：有序且唯一的候选标识、严格递增的共同观察期末日期、每行覆盖全部候选的有限单期收益，以及偶数切片数 `S`。要求候选数为 2–64、观察数不超过 4,096、矩阵不超过 262,144 个值、每半样本至少 30 期，且观察数能被 `S` 整除。仅接受 `S∈{4,6,8,10}`，因此最多精确枚举 `C(10,5)=252` 个分割。该模型不自动填缺日期、补零收益、折算年化或删除失败试验；仅凭日期列表无法证明交易日历中没有遗漏，这项由来源适配器核验。

每个分割按时间顺序把 `S/2` 段作 IS、其余作 OOS；逐候选计算同频率、零基准的样本 Sharpe，选 IS 最高者，再求其 OOS 严格排序名次 `r`，相对名次为 `r/(N+1)`，logit 为 `ln[r/(N+1-r)]`。`PBO` 是 logit 小于零的分割比例。输出保留分割数、低于 OOS 中位数的次数、PBO 与有界逐分割 IS/OOS 指标和名次，便于后续研究产物解释。零方差导致 Sharpe 未定义、IS/OOS 指标并列导致名次不是论文的排列时，明确拒绝计算，交给调用方展示「暂无法评估」，不任意打破平局或把未知算作零风险。

## 验收

1. 手算四切片矩阵验证互补分割、原序拼接、IS 最优候选、OOS 排名、logit 与 PBO；对候选列置换和共同时间顺序的确定性做核对。固定种子的纯噪声家族跨多组样本，汇总 PBO 应接近 0.5，而稳定优胜家族应低于噪声；这只是算法性质检查，不是对任何真实策略的结果。
2. 拒绝日期和矩阵行数不等、重复或倒序日期、列数不齐、重复候选、非有限/布尔收益、切片不等、样本不足、零方差、并列和超预算；不返回部分概率。输入和结果不可变。
3. 在独立 `src/rquant/overfit_pbo.py` 与 `tests/unit/test_overfit_pbo.py` 实现，保持与 PSR/DSR 核心和实验登记解耦。先写聚焦失败测试，再实现最小纯函数；运行本模块相关测试、Ruff、diff 检查，最终候选只做一次独立审查。完成后仍缺完整试验收益来源、实验登记/Lab 适配器、封存产物、Serving 与 React，不得把 PBO 标成已上线。

方法依据：[Bailey 等，The Probability of Backtest Overfitting，Algorithm 2.3](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)。论文文字在 `S=16` 的组合数示例写成 `12,780`，实际 `C(16,8)=12,870`；实现以精确组合数为准。本增量限制到 `S≤10`。
