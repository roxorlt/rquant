# 选股器一句话生成条件：下一片验收边界

本片接原型选股器的「生成条件」入口。复用池子修改所用的受控模型适配器与规则目录；选股器负责草稿、数据日期和真实筛选结果，不复制池子版本化保存逻辑。最终仍需补查询记录、保存预设，以及 AI 助手的「预览结果 → 一键回测」闭环。

**分级：高风险。** 解析可能消耗付费模型额度，用户文本离开本机；沿用池子修改已冻结的凭据、私有入口、限流与不可信输出边界。编码与测试使用离线替身，不调用真实模型。

## 冻结的风险模型

- **资产和边界**：模型凭据仅在 Web 进程的显式私有配置中，浏览器及 Serving 均不持有。用户描述会发送给当前授权的 OpenAI 解析器；其返回值是不可信输入。选股目录与日期来自同一受信来源身份，真正筛选仍由现有 `ScreenApplicationService` 执行。
- **攻击与失败路径**：未登录、跨站或高频请求消耗额度；浏览器伪造数据来源、日期或条件目录；模型编造积木、字段、参数、日期或执行意图；解析期间副本或 Serving 换代；迟到响应覆盖用户后续手改；错误响应清除现有草稿或把旧结果误称为新条件的命中。
- **必须保持**：登录和同源校验、4 KiB 请求上限、每用户限速与单并发闸门先于模型调用；请求绑定当前 `source_kind`、64 位来源摘要及目录内日期，解析前后均重新核对。最多 26 条条件经当前目录、注册表参数模型及编译器验证，并归一化为现有运行 API 可接受的类型；任何不确定性拒绝整个候选。生成不写存储、不运行筛选、不保存池子；用户手动应用后旧结果立即标过期。真正运行时浏览器必须传目录来源身份；Serving 在执行前将它与借用的数据代比较，失配返回 409；Replica 保持现有 `expected_identity` 约束，前端只在身份与日期相符时显示结果。解析失败不泄露密钥、原始模型错误或内部代号，也不清除草稿与已有结果；确认来源换代时清除旧结果。
- **排除**：本片不启用生产模型或调用真实 API，不做查询历史、排名生成、池子保存、一键回测或 Streamlit 切流；这些仍属后续范围。
- **阻断范围**：越权付费调用、接受失效或不可运行的候选、静默执行、泄漏凭据或错误标注命中数均阻断本片；审查限于此风险模型和直接受影响代码。

## 合同与实现切面

- `GET /api/v1/screen/blocks` 增加能力位，只在解析器已显式启用且当前目录有可用来源与日期时开放生成。没有能力时界面仍能手工添加条件。
- `POST /api/v1/screen/nl-preview` 只收 `source_kind`、`source_identity`、`trade_date`、`instruction`，不信任浏览器传来的条件正文；返回同一来源身份和日期下的完整有类型条件列表，不返回假命中数。模型要求不同日期时提示用户先选日期。
- 解析器在公共协议增加新建模式，沿用同一 OpenAI 客户端、超时、额度闸门及异常翻译。池子编辑和选股生成各自验证自己的业务边界，不复制模型接入或筛选计算。
- 前端把建议视为临时草稿：查看、应用、撤销、继续手改、再点现有「运行筛选」。数据来源或日期变更立即丢弃未应用候选；请求迟到也不能覆盖新草稿。
- 现有 `ScreenRunRequest.source_identity` 保留兼容性，但新选股页面对 Serving 和 Replica 均传目录身份。Serving 执行在借用数据代上先比较身份，不匹配就拒绝并要求刷新；响应也须匹配请求身份与日期，页面才可呈现新命中数。这样生成预览后的换代不能通过旧目录把另一代运行结果当成本次条件的结果。

## 用户路径

1. 在选股器输入至多 500 字，点「生成条件」。没有模型运行时就说明「暂不能生成，仍可手动添加条件」。正在生成时只锁住本次按钮，不清除当前条件或已有筛选结果。
2. 页面展示模型建议的**完整条件清单**，逐条用目录里的中文名称与参数值解释。建议不会立即替换手工草稿，也不会自动运行、保存池子或提交回测。含糊、无支持条件、超时和服务错误都保留原草稿，给出下一步。
3. 用户点「应用到条件」才替换条件行；可撤销本次应用并继续手工改参数。应用后旧筛选结果明确过期，用户点现有「运行筛选」获取同来源身份、同日期的真实命中数与分页。
4. 模型只生成过滤条件；排名权重、池子保存、查询历史及一键回测另按原型相邻功能接线，不能把此片称为 C14.1 完成。

## 服务边界

- 请求只含受信来源的数据代/副本身份、选中的交易日期和描述。Web 在一次借用中核对条件目录与来源，释放借用后解析，返回前重核来源身份。浏览器规则正文不能成为服务端验证基准。
- 输出先经 `ScreenPlan`、注册表参数模型和现有选股请求目录约束校验；最多 26 条，限制总 JSON 大小，拒绝未知积木、尚未开放字段、非有限数及不可用日期。模型改变日期或要求执行其他操作时不暗中照做。
- 前端保留一次候选与原草稿；数据来源换代或日期变化使候选失效。模型适配只做解析，选股计算仍由现有 `ScreenApplicationService` 完成。

## 聚焦验收

- 假解析器覆盖新增/删除/改参数、重复条件、含糊、空结果、非法字段/越界参数、迟到响应和来源换代；解析失败不会清空草稿或旧结果，确认换代会清除旧结果。
- `preview → apply → Serving 换代 → run` 必须以 409 拒绝旧身份，刷新后重新运行才展示新结果；Replica 既有换代回归保持通过。
- 受保护 API 覆盖未登录、跨站、超长、高频、不可用模型与数据来源换代；零真实网络请求。
- 桌面、390px 与键盘路径可完成生成→预览→应用→手改→运行；页面正文无内部标识与虚构命中数。
