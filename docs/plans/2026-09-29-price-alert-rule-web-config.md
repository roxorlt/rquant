# 价格提醒规则：私有配置与页面

接续价格规则事务权威、私有 UDS 准入、同代 Serving 投影及 Web 代理身份验真。目标是让用户在盯盘页查看自己的价格规则，并以真实命令创建、修改、开关及删除。此片不运行价格评估或发送通知；在评估与通知链有证据前，页面必须明确显示「价格提醒尚未运行」，不能把规则开关或命令成功写成「已开始提醒」。

**分级：高风险。** 这里跨越认证身份、用户私有规则、PageControl 写入权威及 Serving 读副本；错误 owner、旧数据代或不确定回执都可能造成跨用户泄露或误报操作结果。基线 `fd6e7267`，独立工作树 `cdx/20260929-monitor-price-rule-ui`。本片不修改生产 nginx/systemd、凭据、真实数据库、旧 monitor 或推送模式。

## 设计边界

- **各层职责**：PageControl SQLite 继续是规则唯一写入权威；Serving 从一个固定 PageControl 审计快照发布规则及名单；Web 只借用一个已核验数据代，做 owner 过滤、请求准入和私有 UDS 命令转发；React 只处理草稿、操作状态与展示。Web 不直连主库，也不把页面状态当成规则权威。不为三种命令另造通用框架。
- **读取**：私有 `GET /monitor/rules` 须通过既有代理身份证明。一次借用同代读取 `price_alert_rule_state`、`price_alert_rule` 与手动名单，复核来源状态、行数/摘要/唯一键和名单作用范围；只返回认证 owner 的有界规则，包含已失效绑定的解释所需状态，但不显示其他用户事实或内部代号。旧代缺表、未激活、坏表、坏行、换代和过期分别落入有限的不可用/未就绪状态，不能把未知报成「暂无规则」。规则版本及稳定 ID 留给操作协议，页面正文只显示名称、股票、条件、时间和简短状态。
- **写入**：受保护 `POST /monitor/rules/commands` 接 `save_price_alert_rule`、`set_price_alert_rule_enabled`、`delete_price_alert_rule` 三种有类型请求，要求代理证明、CSRF、显式配置的价格规则私有 UDS、同代及 CAS。浏览器不能提交 owner。Web 先按 `(认证 owner, 原命令 ID, 完整命令)` 精确 lookup；已有命令仅续查/续跑原命令。新命令要重核当前 Serving 指针、同 owner 的规则版本以及保存时有效的手动名单版本，然后由 PageControl 再做事务校验。无可信名单或规则状态时拒绝新命令。网络或回执不确定时只保留原命令供续查，不自动生成新 ID。
- **回执与页面**：成功事务回执只证明「已保存，正在同步」；只有较新 Serving 代出现同 owner、同规则 ID、同版本及预期事实/墓碑时才称「已保存」或「已删除」。规则开关表示配置意愿；在评估器和通知链接通前，页面持续显示「价格提醒尚未运行」，不展示正在监控的绿色状态。失败、容量满、CAS 冲突、名单失效、旧代、断线、刷新和跨标签恢复均给出能执行的短文案。编辑器仅开放当前权威支持的手动盯盘单股到价/低于价条件与 P0–P3；其他范围、条件、频率和通道在领域模型及执行链完成前不作虚假可用控件。

## 冻结失败模型与验收

1. **跨用户与伪造**：直接请求、错/缺代理证明、重复用户头、JSON owner、另一用户的规则 ID/命令 ID、伪造名单版本均不能读取或写入别人的规则。GET 和 POST 共用 `require_current_user`，普通 TCP 及未配置私有 UDS 不开写。
2. **来源与时点**：规则和名单必须来自同一个新鲜 Serving 数据代；坏摘要、缺 state/facts、WAL/SHM、旧代、过期、名单移出/到期/重加、版本变化都 fail closed。数据代 A→B 后旧表格与编辑草稿不能直接提交。
3. **命令恢复**：同一请求重试和断线后的 lookup/resume 不重复写；不同内容/owner 的同 ID 冲突；成功回执与已发布事实区分，删除墓碑和开关版本准确；未知回执不显示成功。三种命令的边界、100 条容量及 CAS 错误有聚焦红绿行为证据。
4. **交互**：桌面与 390px 页面可查看、创建、编辑、开关、删除及续查；键盘可操作，空态/加载/错误与中文文案符合 `web/AGENTS.md`。OpenAPI 类型与前端生成类型一致，相关 Python/Web 测试、构建、产物核对及至少一条浏览器路径通过。独立终审一次覆盖当前 diff 和本节标准。正式 Serving 数据代、真实代理/双 UID、评估、通知及 Streamlit 退役另按既有门禁验收。
