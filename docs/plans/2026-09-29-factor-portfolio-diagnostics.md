# 因子分组组合诊断核心

**等级与范围**：普通任务。只补 C3.2 的纯计算分组收益曲线与目标权重变化近似；原候选基线 `38573c01`，整合基线 `53fbd0c1`。不接数据库、PIT 来源、Lab、Serving 或页面，也不将结果称为可交易回测。

## 口径与边界

- 复用 `FactorEvaluationInput`，沿用已有的方向排序、同值按股票代码排序及 3/5/10 组均分规则。将分组成员划分提取为同包私有函数，避免两套规则漂移。相比重用只有均值的 `GroupingResult`，此方式能算相邻期成员权重；相比复制排序与分组，又只有一个事实来源。
- 每个已提交决策日须覆盖完整的冻结股票池，且所有股票有同一决策时刻和同一收益结束时刻；按决策时刻升序，前一期结束时刻不得晚于后一期决策时刻。输入没有交易日历，因此调用者负责证明未遗漏本应提交的日期、统一复权/成本口径和收益来源。任何缺池、混合窗口或跨期重叠均拒绝整次累计计算。
- 组内是股票后续收益的等权均值；逐期累计值按 `∏(1 + 组收益) - 1`，最优组减最弱组的逐期收益也按相同方式累计。单股或多空逐期收益低于 -100%、非有限或复利溢出时拒绝。少于请求组数则该组数状态为 `insufficient_samples`，不给空组或虚构曲线。
- 调仓日组内目标权重皆为 `1 / 成员数`；相邻两期按股票代码集合计算 `0.5 × Σ|新权重 - 旧权重|`。首期为空值。该数只表示等权目标持仓变化，未模拟价格漂移、成交、交易费用或实际交易量。
