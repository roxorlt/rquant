# M8 实验记录只读分页：冻结失败模型（2026-09-29）

## 资产与信任边界

- 私有 SQLite 实验注册库保存预注册、尝试状态、结果及多重检验调整；`ExperimentRegistry` 是唯一写端，`ExperimentRegistryReadonlyReader` 只通过已验证的只读快照访问它。
- 本变更在写端初始化时新增两条分页索引；读端强制使用索引，不建表、不建索引、不修复数据。分页游标只用于导航，不授予写权限。

## 失败路径与不变量

- 旧库缺索引或索引构建失败时，分页必须失败，不退化为全表扫描。数据库路径、WAL 或文件代际校验失败时沿用现有只读快照的拒绝路径。
- 截止时间、家族筛选、首次读取时的注册上界及 `(registered_at, experiment_id)` 键集边界必须在续页保持一致；每页最多读取 `page_size + 1` 条尝试，并验证所读索引列与载荷一致。
- 损坏的尝试、结果或调整行不得产生部分成功的页面。尝试状态与结果采用每次读取时的当前值；`as_of` 只冻结注册可见性，不承诺历史状态回放。
- `family_adjustment.adjusted_p_value` 只有写端保存的一份权威值；分页只校验其合法范围、身份与时间，不重算整个家族的 BH 调整，因此不能独立证明一个形式合法但被篡改的调整值在统计上正确。

## 明确排除与发布门槛

- 本切片不执行生产库迁移，不接入 Serving、Web 或页面，不改变既有 promotion 读取路径，也不修复或重算历史证据。
- 在生产库运行会补建索引的写端初始化属于生产数据库迁移，必须单独取得用户明确授权，并在授权后的发布流程中验证备份、迁移耗时与读端行为；本地测试通过不构成该授权。
