# 因子研究：日线横截面数值算子

**范围与分级**：普通任务。接续已审查的受限定义与时序求值，仍只在 `rquant.factor` 内做离线纯计算；不接数据库、Serving、网页或研究任务。风险在于把其他股票或未来日期的值误用到当前决策，因此最终候选一次独立审查。验收是同日、同池、同可见时刻的可复算结果，缺值不补齐。

## 算子口径

- 在现有 `FactorTimeSeriesInput` 的固定股票池和逐日决策时刻内支持 `cs_rank(x)`、`cs_zscore(x)` 和 `cs_winsorize(x, k)`，包括与 `ref`、`ts_*` 相互嵌套。每个横截面只取该日池中有效的 `x`；某股票的 `x` 缺失时保留原缺失原因，不作为 0，也不进入其他股票的分布。所有算子沿用输入的股票数、日期数、观察数和结果点数上限。
- `cs_rank` 用升序平均并列名次除以有效股票数，范围 `(0, 1]`；仅一只有效股票时为 1。`cs_zscore` 用总体标准差（`ddof=0`），有效样本不足 2 个时留空 `insufficient_samples`，零方差时留空 `zero_variance`。
- `cs_winsorize` 把有效值截在 `median ± k × 1.4826 × MAD`，其中 MAD 是各值与中位数的绝对差的中位数；MAD 为 0 时上下界均为中位数。`k` 已由定义解析器限定在 0.5–10。本片不对截断后的值自动标准化。
- 一个股票的横截面结果依赖同日参与分布的所有有效值，`latest_visible_at` 应取这些输入及其嵌套表达式所用输入的最晚可见时刻。`ref(cs_rank(x), 1)` 用前一交易日的横截面；`cs_rank(ref(x, 1))` 用当前池中各股上一交易日的值，不从股票自身的有值日回看。
- `industry_neutralize` 与 `size_neutralize` 仍整批拒绝为 `unsupported_operator`：行业身份与市值暴露尚未进入输入契约，不能以任意目录列猜测。遇到无法有限表示的中间统计量，沿用稳定的缺失原因，绝不返回 NaN/无穷。

## 验收

1. 多股多日手算样本覆盖名次、并列、标准分、MAD 截断、零方差、缺值排除，以及横截面与时序的双向嵌套；改变同日另一只股票的值会改变依赖它的结果与可见时刻，不改变其他日期。
2. 已有输入校验、PIT、交易日回看和大小限制保持有效；中性化函数仍整批拒绝，没有部分结果。对重复调用输入，结果稳定。
3. 只跑直接相关因子测试和 Ruff；最终候选一次独立审查。完成本片仍不得把因子检验页面标为已上线，后续需接中性化输入、真实 PIT 数据、检验任务、产物、Serving 和 React。
