# 因子研究：日线时序表达式求值首片

接续已冻结的受限因子定义。任务定级为普通：新增离线纯计算，不读取数据库、调用模型、写研究产物或改变生产服务。先让表达式在明确的股票池、交易日与可见时刻上得出可复算的值，再接跨股票算子和真实数据适配。当前首片不能被页面称为完整因子检验。

## 输入与边界

- 跨模块输入和输出用不可变 Pydantic 模型；定义、股票池、升序交易日、各日决策时刻与逐列特征观察显式传入。每个观察包含股票、交易日、目录内列名、有限数值或明确缺失，以及带时区的首次可见时刻。相同股票、日期、列的重复观察拒绝；越过该日决策时刻的观察拒绝，不能从最终查询时刻倒灌历史值。
- 交易日序列是唯一的回看坐标。缺一天或某股某列缺值时，不向前填充；`ref(x, n)` 取第 `n` 个前序交易日，不取该股票上一个有值日。输入总行数和股票数有明确上限，超限拒绝整批。
- 从已验证的 `FactorDefinition` 重新解析 AST，并仅在白名单节点上递归计算；不使用 Python `eval`、`exec` 或任意函数分派。结果带因子 ID、版本、决策日期、每只股票的有限数值或稳定缺失原因，以及用于该值的最晚可见时刻。

## 本片算子与数值口径

- 支持有限常量、目录列、加减乘除、一元正负、单次大小比较，以及 `ref`、`ts_mean`、`ts_std`、`ts_delta`、`ts_rank`、`ts_corr`。布尔比较结果为 1 或 0；除零、溢出及精度不可表示留空并给理由。
- 滚动窗口要求连续的所需交易日均有有效值。`ts_std` 用样本标准差，`ts_corr` 用 Pearson 相关，至少两个值且非零方差；`ts_rank` 是当前值在窗口内的平均并列名次除以窗口长度（范围 0–1，单值窗口为 1）；`ts_delta(x,n)` 为当前值减去第 `n` 个前序交易日的值。窗口不够、缺列和零方差均明确留空。
- 横截面函数 `cs_*`、行业和市值中性化留给下一片；包含它们的定义在本片以稳定的“不支持该算子”结果拒绝整次求值，不能返回部分计算值或供页面展示为已检验。

## 验收

1. 多股、多日合成样本与手算比对 `ref`、均值、标准差、相关、排名和嵌套算式；同输入重复求值结果相同。
2. 未来可见观察、交易日缺口、重复行、目录外列、窗口不足、除零、零方差、非有限值与规模超限均有聚焦回归；没有静默前填或泄漏异常堆栈给跨层调用方。
3. 代码只放 `rquant.factor`，不引用 Web、Serving、PageControl、行情 SDK 或旧模拟盘 `FactorSpec`；相关因子回归、Ruff 和一次独立终审通过后才冻结。后续必须接同源 PIT 数据、跨股票算子、检验任务、产物、Serving 和 React，不能把离线算子当成原型页完成。
