# 任务页研究任务操作：从已发布状态到受控命令

原型任务页的研究任务需要暂停、恢复、取消和重试。现有 Lab Job Center 已有这四种命令、版本 CAS、命令 spool 和 PageControl 唯一写入口；React 任务页目前只读。此片只把现有能力接到受控 Web 页面，不新建调度器或第二份任务状态。**分级：高风险**，因为操作共享研究任务，且失联重试涉及幂等与并发状态。

## 威胁与失败模型

- **资产和边界**：Lab Job Center 的权威状态、命令 spool 与 PageControl 回执是写边界；Serving 的 `lab_jobs` 是可延迟的只读快照；Web 私有入口负责验证登录身份、CSRF 与单独配置的精确操作员名单。浏览器传来的任务 ID、操作、版本、命令 ID 和数据代只能作为请求参数，不是授权或权威状态。
- **失败路径**：普通登录用户伪造 POST；在公开 TCP 或未配置私有入口时调用；浏览器发送任意 Lab 命令/自定义理由；已发布的可用操作因状态变化而过期；错误版本仍执行；一次提交失联后换命令 ID 重复执行；PageControl 回执未完成或含糊却显示“已暂停/已取消”；跨用户缓存或权限撤销仍保留操作入口；旧 Serving 数据代没有操作字段却被当作可控。
- **不变量**：只有私有入口中的精确操作员可以发起四种固定动作，Web 强制 CSRF、请求大小及类型边界，服务端构造命令和理由；PageControl 及现有 Lab Facade 保持唯一写者并对当前版本和动作可用性作最终判断。页面上的快照动作仅供提示，不能替代权威 CAS；原命令 ID 的失联重试必须可恢复，任何非终态回执只称“已提交/待确认”，不称任务最终状态。没有权威版本、动作可用性或身份时不显示可用操作。旧代保持任务只读展示。
- **排除**：不实现新建/重新运行研究任务，不改 Lab 调度算法，不改生产 `deploy/systemd`/nginx/sudoers，不打开 root 单元「立即运行」，不写主 DuckDB，不切流或停 Streamlit。生产入口和权限安装仍需按项目规则另行验收与授权。

## 实现边界

1. 在同一 `LabJobSummary` 来源快照发布版本和四种动作可用性；Web 保持旧 Serving 代只读兼容，不从状态文字猜版本。只给已登录且在独立 `lab_control_users` 名单内的用户返回可用操作，默认名单为空且必须有私有 Web 入口。权限改变即撤掉页面控制。
2. Web 仅接收 `pause|resume|cancel|retry`、规范 UUID、期望版本及稳定命令 ID；服务端构造 `SubmitLabCommand` 和固定理由，将登录用户绑定到审计交互键。经现有固定 loopback PageControl 投递，核对外层回执和内层 `CommandSubmissionResult` 的命令/任务身份，映射为有限中文状态。原请求重试保留同一 payload；换版或动作不支持返回明确冲突，不静默重试新版本。
3. React 在任务行或进展抽屉提供当前可用动作。取消和重试用现有确认框说明影响；提交后显示短句“已提交，等待状态更新”，等待下一代任务状态确认。失联或未决保留原命令并提供“查询/重试”，刷新和多标签不会把未知变成功；键盘、390px 与简短中文文案保持现有设计体系。

## 验收

- 未登录、非操作员、无私有入口、CSRF 缺失、超长/非法请求均不会到达 PageControl；正常操作与旧 Serving 代只读展示有聚焦用例。
- 与现有 Lab Facade 的 CAS/可用性结合验证允许、版本冲突、动作不可用、同一命令重试、失联/含糊/非法回执和身份隔离；没有“提交成功=任务最终完成”的误报。
- 生成 OpenAPI 与 TypeScript 类型，完成相关 Python 聚焦回归、`pnpm -C web check`、构建/产物校验及桌面/390px 关键交互。最终候选仅在本威胁模型范围做一次独立审查；没有新风险证据不扩到全仓或生产。
