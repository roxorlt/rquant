# 日线因子表达式的逐日流式求值

**目标：** 接续已验收的股票池选择与流式统计，从有界逐日特征批次产生完整因子横截面；公式不再依赖全期股票 × 日期矩阵。数值口径继续由现有受限表达式和纯算子负责，为后续同源读取、收益事实与网页「运行检验」接线提供真实计算能力。

**任务分级：普通任务。** 新增离线领域计算及相关测试，最多提取同包纯算子助手；不改权限、生产数据、持久任务或既有产物合同。主要风险是历史横截面被今日名单重算、窗口缺数前填、过度保留全期源对象和数值口径漂移。按聚焦红绿证据及一次最终独立审查收敛。

冻结实现基准为本地集成提交 `7f29d29d132baca61d92d182dd635cc3d611b474`。允许写 `src/rquant/factor/formula_stream.py`、`tests/unit/test_factor_formula_stream.py`；为复用现有数值口径，可在 `time_series.py` 及其直接测试中做最小纯助手提取，须先向 orchestrator 说明具体重复点和 diff 边界。旧 `FactorTimeSeriesInput`、历史适配器、结果与 Web 合同及其容量保持不变。

## 输入与职责

- 请求固定不可变定义、目录、精确升序交易日日程及各日决策时刻、截止 `as_of`、股票池选择和明确来源身份。计算代码清单是预先钉住的有界证券集合（最多 7,000，覆盖本次所有逐日清单），不是外部全市场覆盖证明；全市场事实完整性仍由来源层证明。日程最多 1,024 日，含预热日。
- 每个原始批次含当天 `FactorUniverseRequest` 的完整证券/必要指数事实及特征点。调用既有 `select_factor_universe` 取得当天合法股票池，不接受调用方手填输出名单；请求的选择、日期、截止和来源绑定须精确一致，事实清单不得出现计算范围外的证券。
- 特征只支持已决定的 `HISTORICAL_DAILY_V1` 六字段及可运行算子；行业/市值中性化缺正式事实，继续拒绝整次求值。每个计算证券与定义依赖列须恰好一个特征点，有限值、已观察的空值及缺观察明确区分；重复、漏项、额外证券/列、不同日期及未来可见时刻均拒绝，不能缩池。无依赖常数无需特征点。
- 特征的来源面板日、日线读取与历史回溯可见假设由后续来源适配负责。本片只核对带时区的可见时刻不晚于对应决策，不能将其称为真实当时采集。证券/指数源的实际观察时刻遵守现有历史回溯合同，不提升为前瞻数据。
- 所有新跨层模型严格、冻结、拒绝额外字段并重新校验实例。只输入一次性迭代器，不读取数据库、网络、配置、Serving 或旧 Streamlit。

## 逐日与窗口语义

1. 消费日程恰好一次，批次缺日、多日、重复、乱序或迭代失败均传播稳定拒绝；完成标志只可在迭代自然结束并核验全日程后产生。已 yield 的单日值是中间事实，不能据此标记整个研究成功；后续统计消费者须耗尽并拒绝失败的整个运行。
2. 算术、一元、单次比较、`ref`、`ts_mean/std/delta/rank/corr`、`cs_rank/zscore/winsorize` 的有限值、精度、缺数原因、并列名次和最晚可见时间与已有求值器一致。使用同包纯数值助手或最小提取，不能复制一套不同口径。禁止 `eval`、`exec` 和任意函数分派。
3. 时序算子按固定交易日日程定位，计算清单中未入当天池子的股票仍有原始特征历史；缺观察/空值保留缺失，不能取上一个有值日替代。新入池证券若有完整特征预热可直接求值，缺历史则明确缺数。定义最早日期之前的输出缺失，但实际原始特征仍可供应后续窗口。
4. 每个横截面节点只在其自身历史日期的所选池内计算，先完成整个横截面再得到排名/标准化/MAD；池外该节点明确缺失。`ref(cs_rank(close), 1)` 或 `ts_mean(cs_rank(close), n)` 必须使用当时已经确定的横截面，不能用今日入池成员回算。纯时序节点的历史不因成员进出被抹掉。
5. 仅保留当前源批次和节点所需的有界历史值。历史保留长度由 AST 的实际父节点回看需求决定，不随全期日数增长；缓存中的值是轻量纯数据，不保留 FeaturePoint/Pydantic 源批次。固定清单与日程可常驻，结果交给消费者后不汇总全期逐股值。
6. 实施前计算保守节点历史槽位预算；默认最多 2,000,000 个槽位，超限在读取迭代器前明确拒绝，不能分块平均横截面或静默缩窗。这是代码资源上限，不是实测的全市场性能门限；须记录预算口径，后续真实副本测量再决定生产承载能力。
7. 每日输出绑定定义、原请求摘要、当天真实选择结果与因子值，并提供确定性输入/历史链摘要。同行排序不改变结果或摘要；定义、截止、来源、成员、可见时间、原始值或窗口事实改变须改变相应摘要。空选择仍输出合法空横截面，不当作缺来源。

## 实施与验收

- 先通过小型固定池逐日输入与现有批量求值器比对全部可运行算子、嵌套窗口、精度和缺数；再手算动态入出池、历史横截面、明确空选择、常数和最早日期的行为。
- 覆盖重复/漏项、错来源/日期/日程/可见时刻、容量及预算拒绝、一次性迭代器与下游失败传播。证明以前源批次及特征对象在消费下一日后释放，窗口淘汰后旧历史值不残留。
- 用生成器运行一次有界合成规模测试：7,000 股、至少 16 日（超过旧 100,000 点整期上限），至少包含滚动与横截面算子；输出逐日消费，不保存全期列表。记录样本尺寸、实际 Python 分配峰值、结束保留和批次释放。该结果不代表真实约 10 GB 副本、RSS 或生产性能通过。
- 用已有 Python 3.12.13 离线环境，禁用 dotenv/通知，所有合成文件在临时目录。聚焦新增、旧时序/横截面及直接受影响纯依赖；Ruff、格式和 diff 检查；不自动跑全仓。冻结候选只安排一次独立终审，普通任务最多一次定向修复和复核。
- orchestrator 负责本地集成、清单与进度；实现者不得继续委派、修改计划或发布。正式来源按日读取、收益/衰减、受控任务与 React 入口继续在后续切片接通。
