# 因子冻结快照的只读准入

接续 [因子数据来源与时点口径](2026-09-29-factor-frozen-source-design.md) 的高风险前置片。本片只让因子研究从一份已验证、专属于 `factor_eval` 的历史快照读取固定日线事实；不计算因子、收益或生成 Lab/网页产物。

**分级：高风险。** 扩展共享 `ResearchExecutionSession` 的可见查询面，并为研究用途登记独立数据绑定；错误会把未核验或跨代事实交给后续报告。资产、信任边界、失败路径、不变量、排除项及阻断条件以来源设计文档的“高风险前置”节为冻结 threat model。本片不修改现有正式策略的准入/资格覆盖语义；因子历史回溯仍标探索性，不能借该租约获得“可比较/模拟候选”状态。

## 合同

1. `factor_eval` 有精确版本的数据依赖：`daily_bar`、`adj_factor`、`trade_calendar` 三张物化表，零分钟湖分区；构建绑定时必须用该依赖而不是 `n_shape` 等策略的依赖。现有三个正式策略依赖保持原样。注册允许零湖分区时，仅当明确使用 `factor_eval` 合同时才可用，不能让普通正式策略退化为空依赖。快照身份、绑定摘要、合同版本、表名/数据集 ID、物化工件与行键都要核对。因子专用 builder 使用与元数据写连接分开的源连接，在**同一个 DuckDB 一致性读事务**中物化三张表；事务不能由调用方预先开启，开始/完成边界由 builder 控制，无法建立一致读取即拒绝。准入回执绑定 `snapshot_id`、`binding_hash`、源快照的 `as_of_time` 和 `source_read_boundary=single_snapshot_transaction`，不把三个独立读取时间伪称同一源。
2. 新增独立 `FactorSnapshotAdmissionRequest/Decision` 和上下文管理入口：请求明确快照、绑定摘要、范围及 `source_mode=historical_retrospective`；入口只检查 `factor_eval` 快照、完整专属绑定、精确三工件与版本、请求范围，然后打开并核验**同一** `ResearchExecutionSession`，才交出因子只读租约。决策恒为 `exploratory`，不能使用现有 `open_gated_research_store` 的策略资格/覆盖率语义，也不改动该入口。拒绝时给封闭原因，不交出连接或租约。因子租约只公开固定的日线 `ts_code/trade_date/open/high/low/close/vol/amount`、复权因子及 SSE 日历 `cal_date/is_open/pretrade_date`；每次查询带精确绑定摘要、排序去重后的有界股票池和日期范围。数据跨层用有类型不可变结构；不返回 DuckDB 连接、原始 SQL 或任意列名。查询关闭的会话、错误代、缺/多/重复工件、错误版本或缺表时失败关闭。参数化值，固定 SQL 标识符；限制股票数、日期跨度和返回行数，防止请求耗尽内存。表行重复键、日历重复/冲突时拒绝。
3. 同一租约中的三类事实必须来自同一次冻结事务物化、同一绑定的核验工件。生产主库、只读热备、Web、Serving、模型或网络都不参与本片。快照可包含事后修订，租约不推断 `first_visible_at`；日期可见性与复权收益留给后续适配器，且不得把原始行包装成当时实采。

## 先写失败用例，再实现

- 用本地合成 DuckDB 源构建 `factor_eval` 绑定、关闭后再由专用准入入口打开核验会话；读取 3 股、跨周末日历与价格/复权行，检查绑定摘要、字段和排序。源库在绑定后改变，租约值不变；不存在生产数据依赖。
- 在三表物化之间尝试由另一连接修改源行：要么同一事务仍读到修改前的完整三表，要么构建明确失败，绝不拼接修改前价格和修改后复权因子；回执保留源快照/事务边界。错误合同版本、非 `factor_eval` 绑定、缺日线/复权/日历、重复工件、损坏摘要、跨代请求、关闭会话、越界代码/日期/行数、重复股票与重复业务键均有明确拒绝用例。未在工件中出现的股票/日期保留为空，不伪造零行事实。
- 有效因子绑定**无需策略资格/覆盖率**也只能获因子租约和 `exploratory`；缺绑定/错代因子准入拒绝，且同样输入不能让正式策略 `open_gated_research_store` 放行。原正式策略绑定与门禁聚焦测试仍通过；`factor` 领域模块不访问 `_conn`。源读取只测返回与拒绝行为，不为实现细节写镜像测试。测试固定清单按实际新增节点更新。

## 冻结与验收

实现以本分支的明确 diff 为边界，使用小夹具先红后绿，跑相关快照、门禁、依赖与因子测试、Ruff、diff 检查；只有共享合同确需更广回归时才扩大。最终候选请一名独立审查者一次性检查本片 diff、直接依赖、测试及此验收。未得到公开租约和专属绑定的因子来源适配器不得开始；本片通过也只证明“冻结事实可被有界读取”，不证明 PIT、收益或页面已实现。
