# 因子研究：受限定义与表达式首片

按原型「因子研究」页及 `frontend-plan-v2.md` C3.1 先建立领域定义边界。本片只验证和规范化因子表达式，不计算因子值、不保存 PageControl 定义、不发布 Serving 表，也不把示例图表当作真实结果。任务定级为普通：新增一个纯领域契约和解析器，未触及生产写入、权限或外部执行。

现有 `rquant.signal_provenance.FactorSpec` 是模拟盘入场信号的命中项，不是研究因子定义；保留原类型和用途。新类型放在 `rquant.factor` 下，依赖通过显式特征目录注入，不从 Web、数据库、全局配置或 Notebook 导入。前端将来只显示中文名称、分类、可用起日和检验结果；表达式等技术细节放在详情。

## 验收

1. 有类型、不可变的研究因子定义包含稳定 ID、中文名、分类、方向、版本、最早可用日、表达式及解析得到的依赖列。依赖列必须来自调用方给定的有界特征白名单；空白、重复、非法列或与表达式不一致的声明拒绝。
2. 只通过 Python AST 的显式白名单解析表达式，**绝不 `eval`/`exec`**。允许有限数值常量、白名单特征名、`+ - * /`、一元正负号、单次 `< <= > >=` 比较、括号；函数只允许 `cs_rank`、`cs_zscore`、`cs_winsorize`、`industry_neutralize`、`size_neutralize`、`ts_mean`、`ts_std`、`ts_delta`、`ts_rank`、`ts_corr`、`ref`。函数参数个数固定，窗口和 `ref` 偏移为显式整数常量且有上限，负偏移拒绝；`cs_winsorize` 的 MAD 倍数须有显式安全范围。不同函数的真正数值语义留给后续求值器，不在本片伪造。
3. 限制表达式长度、AST 节点数、嵌套深度及特征目录大小。拒绝属性、下标、列表/字典、推导、lambda、赋值表达式、关键字或星号参数、字符串、布尔逻辑及任何不在白名单的 Python 结构。错误用稳定的领域理由，供将来 Web 转成简短中文提示。
4. 解析结果给出规范表达式、排序后的实际依赖和所需最大历史窗口；同一表达式与目录重复解析得到同一结果。类型注解完整，跨层结果用 Pydantic，不把 AST 对象穿过层边界。
5. 聚焦回归覆盖合法组合、重复/未知列、非法结构、未来引用、巨大窗口/深度、常量 NaN/Inf、目录换代造成的拒绝，并证明没有导入旧模拟盘写路径或执行任意代码。
