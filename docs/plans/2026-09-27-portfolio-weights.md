# 组合目标仓位纯计算

> 2026-09-27。对应新前端计划 v2 的 C9.1 第一增量。只提供可复用的目标权重计算，不接模拟账户、回测执行、网页或生产调度；M9 仍为「部分」。

## 分级与边界

这是**普通任务**：新增独立的纯领域包 `src/rquant/portfolio/`，会改变未来模拟组合的目标权重算法，但本增量无生产数据、下单、权限或共享存储写入。输入与结果使用 Pydantic/类型注解；给定同一候选、约束和资金，输出确定且不依赖数据库或网络。保持领域层只计算**目标权重**，回测和模拟盘后续共用它；不在这里复制撮合、T+1、涨跌停和 A 股整手成交逻辑。

## 验收

1. 支持等权、按非负排名分加权；按明确的稳定顺序选前 N，执行单票上限、申万一级行业上限、目标现金保留比例、最小目标金额。未知行业在启用行业上限时不得绕过约束。输入中重复股票、非有限数、负分/资金和不合法比例显式拒绝。
2. 超限部分按剩余股票的原始权重比例反复分配，直至达到投资目标且单票/行业均不超限；受最小目标金额剔除的股票不被偷偷恢复。无可行解（候选太少、单票/行业上限不足、最小目标金额与资金冲突等）返回清楚的领域错误，不输出看似已满足的半成品。
3. 权重非负，投资权重之和加现金权重为 1（定义一致的数值容差）；输出按稳定顺序并标明入选/剔除原因，后续页面可映射成简短中文。资金和权重计算使用可复核精度，舍入不越过上限；A 股 100 股整手及真实订单最小金额由后续撮合层处理，当前“最小目标金额”仅判断目标持仓额度。
4. 先用手算样例写红测，覆盖等权/评分、并列、两种上限同时绑定、剩余权重再分配、现金、最小金额反复剔除、不可行、零投资、输入顺序变化。测试须核对具体权重，而非只复述实现。跑聚焦回归、Ruff、diff 检查；最终候选安排一次独立审查。普通任务最多一次定向修复复核。
