# 策略目录 React 页面首片

类别：普通任务。只改网页中的策略只读展示，不触及定义写入、晋级、交易或生产发布。基准为 `cdx/20260929-strategy-catalog-read` 的 `0bdfda11`；该基准的 `/api/v1/strategies` 只发布三个已核验的内置策略及各自当前参数。

## 本次验收

1. `/strategies` 从有类型的 `useStrategyCatalog` 读取真实 Serving 结果，显示策略列表，支持点击、Enter/Space 和方向键选中；详情只展示 API 确认的中文名称、当前版本、登记时间和参数。
2. 首屏、刷新、出错、来源不可用和数据代变化均有明确状态；数据代变化后不得继续展示旧策略详情或保留无法核验的选择。
3. 页面正文不显示内部策略 ID、数据代、服务代号，也不把原型中的示意年化、夏普、阶段、晋级证据或历史版本当作真实事实。新建、回测、晋级按钮在实际写入/产物能力接通前不出现。
4. 桌面和 390px 页面可读，键盘焦点可见；文案遵守 `web/AGENTS.md`。参数标签/值以 API 的受信中文文本显示，不在页面补造解释。
5. Vitest 以真实 API 契约的合成响应验证列表、选择、状态和换代；Playwright 覆盖桌面、390px 与键盘操作；运行前端检查、构建与提交后 `verify:dist`。

## 后续边界

此片只使 C5.2 的现有内置策略目录可看。受控模板与保存、版本历史、回测关联、阶段证据和晋级仍列为 M5 未完成，不视为 Streamlit 替代条件。
