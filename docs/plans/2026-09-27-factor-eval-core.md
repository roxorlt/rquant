# 单因子检验：纯计算核心

**目标**：为 C3.2 建立可复用的日线横截面检验口径，先输出逐日 NormalIC、RankIC、分组等权后续收益和样本数量。Lab 任务、产物索引、长区间统计、页面与正式数据源随后接入；本增量不能被称为因子研究页面上线。

**等级与基线**：普通任务；只新增纯计算模块及聚焦测试，不更改数据、权限、发布契约或生产服务。基线 `1511aded`，隔离分支 `cdx/20260927-factor-eval-core`。实现与审查只限该模块及直接依赖；最终候选做一次独立审查。

## 数据与口径

- 调用者提交一个已封存的股票池和若干决策日的样本。每条样本必须带股票代码、决策时刻、因子值的可见时刻、因子值、后续收益观察结束时刻及后续收益。因子值在决策时刻之后才可见、后续收益窗口未结束或时区不明的输入一律拒绝。收益是调用方在同一观察窗口、复权和交易成本约定下计算的输入；当前纯核心仅核对每条样本的时间边界，尚不能证明跨股票窗口一致，后续 PIT/Lab 适配器必须验证。本模块不读取价格、不猜停牌处理，也不把结果称作可交易回测。
- 同一决策日同一股票只能出现一次；非有限值和无效时间范围拒绝。各日独立计算横截面；缺少足够样本或零方差时报告“无法计算”及有效样本数，不把 IC 写成 0。
- NormalIC 是因子方向调整后与后续收益的 Pearson 相关；RankIC 是两者采用平均并列秩后的 Pearson 相关。方向仅影响因子排序，不改变原始收益。分组先按因子方向排序，值相同按股票代码稳定排序，尽量均分为 3/5/10 组；每组输出等权平均后续收益及成员数。分组不足时明确不可计算，不空造组。
- 输出顺序固定：决策时刻升序、组号升序。给每个结果保留源样本数与有效样本数，以便后续页面解释缺口；不返回原始股票代码或内部标识给前端。

## 可验证验收

1. 人为构造完美正相关、完美反相关、并列秩和零方差样本，NormalIC / RankIC 与手算结果一致；方向反转的结果可解释。
2. 两个决策日及重复股票输入能验证按日隔离、稳定组排序、组人数与等权收益；样本数小于分组数时显示不可计算。
3. 时点、缺失时区、NaN/无穷和重复样本在输入边界被拒，且没有数据库、网络或可执行表达式依赖。
4. 聚焦测试和 Ruff 通过；不得为此运行无关的全量测试。集成时再按真实新增用例重生全量测试清单。

## 后续阶段

纯核心通过后，补单因子检验所需的 IC 统计、1–10 期衰减、分组累计收益/换手、行业 IC 与因子自相关；从 PIT 来源生成经研究门验证的输入，并由 Lab 封存结果。页面消费经产物索引验证的产物，不在网页 API 或 React 中重算研究口径。
