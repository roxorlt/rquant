# 公式池的同代网页读取

## 范围与分级

为已经封入 Serving 的公式池定义和最近一次成功逐日结果增加只读 Web 合同，供下一片 React 接入池子画布与「保存为池子」回显。普通任务：只读用户可见合同，不改变身份权限、命令写入、调度或生产配置。直接风险是混合数据代、把上次结果称作今天，或读取已被篡改的成员文件。

## 验收

1. `GET /api/v1/pools/formula` 在一次 Serving 借用中读取状态、定义、最近结果三表及 `projection_status`；同一数据代/来源身份、可用时刻、清单行数和三表内在关系须全部核对。旧代未发布、显式空定义、无 Serving、完整可用分别返回明确状态；只要出现部分表、跨代、畸形字段或不一致，一律返回短中文的暂不可读错误，不回退为零结果。
2. 列表最多 512 个定义，输出有类型的名称、显示名、公式文本、语法版本和创建日期；最近成功结果仅显示其真实交易日、命中/未命中/未知数及安全的中文未知原因。没有逐日结果明确为「尚未运行」；零命中与未知数均如实显示。不得借最近成功日推断今天已完成，也不得将内部路径、任务 ID、摘要或数据代号放进正文文案。
3. `GET /api/v1/pools/formula/{base_name}/members` 只接受受控名称与服务端索引，使用 Web 显式配置的每日结果**只读根目录**精确重读最多 2 MiB 的封存文件；核对规范 JSON、索引摘要、定义版本、交易日、来源身份、计数与完整成员摘要后按每页最多 100 只返回命中股票代码。Web 不接收客户端文件路径，不需要任务库、公式定义私有目录或 PageControl 写权限；缺配置、文件缺失或变动时显示暂不可读，不伪装为空。
4. 分页游标绑定当前 Serving 代、池子名、定义版本、结果摘要、偏移与页长，并用现有服务器密钥鉴别。旧代或旧结果游标返回需重新打开的状态；非法游标、额外查询参数、超限与未登录均按现有 Web 约定处理。列表与成员响应沿用 `Envelope`/`ServingMeta`；旧规则池 `/api/v1/pools` 和公式批量任务接口行为不变。
5. 使用合成 Serving 代与受控每日文件验证可用、显式空、尚未运行、可信零命中、未知、缺/跨代表、成员分页、旧游标、文件篡改、缺配置及身份边界。运行直接相关 pytest、Ruff、OpenAPI/TypeScript 类型、前端构建和产物校验；候选做一次独立终审。

## 边界

- `formula_pool_serving_projection` 负责已审计的定义及结果索引；Web 只借用一代并按索引重读成员。规则池和公式池保持各自有类型的领域合同，不用空 `RuleCall` 或静态成员冒充公式池。
- 本片仅暴露读 API；下一片再接 React 的保存按钮、列表/画布及结果状态。逐日批量调度与生产投影启用另行实现，Streamlit 退役仍遵循逐功能验收及生产授权。
