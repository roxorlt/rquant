# 通达信公式单股预览边界

> 2026-09-27，基线 `d46c345f`。这是 C4.5 的一个可验证增量：在选股器检查公式，并对一只指定股票的已收盘日线作真实预览。全市场命中数、保存成池子和定时运行继续按 `2026-09-27-tdx-formula-import.md` 后续步骤实现，页面不得暗示本增量已完成这些能力。

## 分级与验收

**高风险**：公式是用户输入，历史行情来自约 10.8 GB 的共享只读副本；错误的时点、覆盖范围或数据代会给出看似可信的错误选股结论。先做单股同步预览，保持一次请求的行数、计算量和响应尺寸有界；全市场预览须另行设计异步研究任务或等价可控执行，不在网页请求里循环扫描全市场。

可核验验收：选股器能粘贴公式、看到短而明确的语法/不支持项提示，并在显式配置的核验副本可用时，用选定数据日期和一只股票预览「符合 / 不符合 / 暂无法判断」。真实的合成 DuckDB 副本正例与缺日期、缺历史、缺上市日期、换代、别名/硬链接、未来日、超限及未配置副本反例要有聚焦测试；桌面和 390px 的输入、加载、结果、错误、关闭与键盘操作有行为证据。页面显示数据截至时间，不显示路径、代号、哈希或原始异常。

## 冻结的失败模型

- **资产与信任边界**：浏览器提交的公式、股票代码、日期和来源身份均不可信。解析器与纯求值器只接受白名单表达式；网页 API 校验请求、CSRF 和当前来源；`VerifiedReplicaScreenSource` 只读已核验副本，并在读前后比较 sidecar 和文件身份。主库、WAL、凭据与通知不对网页开放。
- **失败路径**：未收盘就使用当日日线；选中的交易日、公式历史和目录来自不同数据代；股票缺日线却返回“不符合”；上市以来历史不全却把递归 EMA/SMA/BARSLAST 算为确定值；未证明交易日历完整却把缺口当作无行情；换代后旧结果继续显示为新结果；单次公式迫使 10 GB 副本全表扫描或无界向量计算；语法错误回显源码/内部详情；副本不可用时静默退回 Serving 或主库。
- **不变量**：预览只接一只股票，股票代码格式和公式字节数有界；所选日期必须属于当前核验副本目录且已到上海时间 17:00。请求绑定目录的副本身份，读完再核对同一身份；任一不符返回简短中文重试提示。固定窗口需要相应的连续有效历史；递归公式只有上市日期及从上市首个适用交易日起的覆盖可证实时才设 `complete_from_listing=True`，无法证明则返回「暂无法判断」。日历未知和合法停牌的语义如不能可靠区分，保守返回未知。不得将用户公式拼入 SQL；已有纯求值器的行数、字节与工作量上限继续生效。
- **排除**：全市场命中数、分页/排名、保存池子、研究任务、生产权限或服务改动、真实 10 GB/cgroup 压测、切流与 Streamlit 停服。C4.5 保持「部分」。

## 模块与验证

1. 在已有副本源增加单股历史读取，复用同一只读连接及换代核验；按交易日历、上市日期和日线主键证明求值器要求的覆盖，不能证明就返回未知或可解释的不可用。网页路由只处理 HTTP 边界，应用服务协调读取与纯求值器。
2. `POST /api/v1/screen/tdx/preview` 使用 Pydantic 请求/响应；返回股票、日期、三态结论、中文原因与来源更新时间，不输出 AST、路径和内部身份。解析接口继续负责语法检查；前端通过生成的 OpenAPI/TypeScript 合同调用。
3. 选股器的轻量对话框先检查公式，再对单股预览；输入更改或来源换代时旧结论明确失效。帮助放在悬停提示；窄屏、键盘、空态、加载、失败文案按 `web/AGENTS.md`。
4. 聚焦 Python 副本/API/纯求值、前端交互及桌面与 390px 浏览器路径；`pnpm -C web check`、`build`、`verify:dist` 和 diff 自检。最终候选只做一次独立审查，修复/复核按根 `AGENTS.md` 的高风险轮次上限执行。生产副本负载和 service 权限仍是发布门禁。
