# 一句话改池子：只生成可核对的编辑草稿

范围：原型池子画布的「用一句话改池子」。复用已规划的手工编辑器及 `SaveUserPoolV2` 网关；本片只把自然语言转为**完整候选规则**并预览差异，不执行保存。候选通过同一表单由用户逐项检查，再走现有版本化保存与画布挂接路径。

**分级：普通任务。** 生成接口不写池子、画布或数据库；可见规则仍由既有权威命令负责，改动只涉及受限模型适配、API 和编辑器。生产调用第三方模型及其密钥配置遵守当前会话的 OpenAI-only 边界，开发与验证只用离线替身，不调用外部模型。

## 2026-09-28 实现边界

本次补齐可实际接入的解析适配器时，**分级升级为高风险**：网页服务会持有模型 API 凭据，并向模型发送用户的修改描述及当前池子条件。当前只实现和离线验证代码；生产密钥配置、服务变更与实际联网调用留在单独的上线决策中。

### 受限风险模型

- **资产与边界**：凭据只来自网页进程的显式环境配置，不读取 `.env`；付费解析只在 Web 私有入口配置后启用，避免本机其他进程伪造经 nginx 覆写的用户头；浏览器只经受保护入口交请求；Web API 只从已核验 Serving 数据代读取权威定义；模型输出始终是不可信草稿；PageControl 是唯一保存权威。
- **失败路径**：未登录或跨站调用消耗额度；超长或高频请求刷模型费用；浏览器伪造规则、数据代或版本；模型虚构积木、越界参数、重复过多、改变父池或列、返回含内部标识的说明；请求超时、旧数据代或另处编辑后误保存。
- **必须保持**：身份、同源 JSON、大小、频率和并发限制先于模型调用；只用同一已核验数据代的规则作为上下文；候选经目录参数和池子编译器验证，最多 32 条；生成接口零持久写入；前端变更预览可撤销，保存仍通过现有版本化命令；失败不清空原草稿或暴露凭据、原始模型错误。
- **排除**：不在本次写入真实池子或启用生产模型；不替换 PageControl、Serving、选股执行器；不推断未运行候选的命中数量，显示「暂无法估算」。
- **阻断范围**：以上任一不变量失效、前端绕过确认保存或密钥被记录/回显，阻断本片；无关仓库问题不扩展审查。

## 最小数据流

1. 浏览器提交池子键、当前编辑模型的数据代与定义版本、至多 500 字的修改描述。接口验证登录、同源 JSON、`Origin`/`Sec-Fetch-Site`、请求大小与每用户频率；从同一次借用的 Serving 数据代重读**可编辑**的定义，拒绝旧版、不可用或与浏览器基准不一致的规则。浏览器提供的规则正文不作为模型基准。
2. 适配器把权威基准规则和用户描述交给受控解析器。旧 `rquant.llm.client.DeepSeekClient` 的编辑模式可作为输入/输出协议参考；运行时模型供应者须符合用户当前授权。输出先经 `ScreenPlan`、积木目录参数模型和池子 v2 编译器验证，并限制规则数量、参数大小与总预算。父池、延后日、名称和画布引用由手工编辑模型保留，模型不得暗改。
3. 返回类型化草稿：完整新规则、基准版本、逐项增加/移除/参数改变的中文预览和解析器澄清说明。差异比较基于归一化的积木及参数，不把排序变化误报为增删；页面正文不展示函数名、数据代或命令 ID。解析器异常、超时、歧义或无有效变更都保留原草稿并给出简短的下一步。
4. 用户可继续修改草稿；点击「保存」时仍用编辑网关的版本、幂等与发布状态协议。生成成功只表示草稿可预览，不表示已保存、规则已发布或选股已更新。换数据代或另处编辑后要求重新核对，不自动套用旧建议。

## 验收

- 离线假解析器覆盖加条件、删条件、改参数、重复积木、顺序变化、澄清、超时、无效工具结果、越界参数与越权改父池；旧定义在所有失败路径保持原样。
- API 验证未登录、跨站、超长输入、频率限制、旧数据代、内置池及不可编辑定义；零真实模型请求。
- 桌面、390px 和键盘路径能预览差异、撤销建议、手动校正并走同一保存按钮；未确认草稿绝不自动提交，正文没有技术键。
- 如果缺少当前会话许可的模型运行时，页面诚实显示「暂不能生成，仍可手动编辑」；不得静默改用第三方模型。正式在线解析效果与生产配置在获得适用授权及运行环境后另行验证。
