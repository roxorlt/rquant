# 策略页：可信定义与参数首片

## 目标与边界

CC 可点击原型的策略页需要策略列表、版本、规则和参数。当前页面仍是占位，原型中的收益和晋级阶段是示例，不能搬到真实页面。本片从现有不可变 Definition Registry 发布**已经验证的三套内置策略当前定义**，在 React 显示列表与详情；后续实验新建可复用这份同代只读目录。只有定义、版本及实际参数具备证据时才显示；业绩、回测日期、晋级阶段、参数可调范围、版本历史和操作按钮须等各自权威接通。

**分级：高风险。**策略定义及可执行指纹属于共享运行契约；错误的展示若被后续实验入口当作准入依据，会指向错误策略。冻结基线 `59312a07`。本次只读发布和页面，不改 Definition Registry 写者、不提交研究任务、不改生产配置/数据、不部署或切 Streamlit。

## 威胁与失败模型

- **资产/信任边界**：`load_runtime_generation_tree` 验证后的**同一个当前运行时代**提供三份固定 `strategy.*.v1` 的 `STRATEGY_LIVE` 清单；各清单给出 producer commit、定义注册根和精确注册指纹，三者必须同根、同提交、同代。`RuntimeDeploymentReceipt` 本身只证明代与提交，不被误当成包含这些字段的聚合清单。Definition Registry 的内容寻址记录、特征引用及可信执行绑定负责定义真实性；独立来源发布器把有限的展示字段封入 Serving 数据代；Web 只借一个已验证数据代；浏览器无权选择目录路径、提交号或指纹作为信任依据。
- **失败路径**：扫描目录或从未验证 JSON 读取看似存在的策略；当前代码的 evaluator 与旧 producer commit 混用；只验证 spec 哈希却跳过执行绑定；三个策略缺一仍报完整目录；未来版本/参数上限溢出或内部标识进入页面正文；Serving 来源缺失、损坏或旧代时显示“无策略”；某策略从当前代消失后还显示旧详情；拿用户可见目录作为新实验可执行/可提交的授权。
- **不变量**：只接受同一核验代中三份固定 service id、正确 `STRATEGY_LIVE` kind、同一注册根与 producer commit 的精确定义；每份指纹须符合该提交下的 `plan_builtin_definitions` 与 `ImmutableDefinitionRegistry.read_strategy_spec` 的执行图核验。发布前重新核对当前运行时代指针仍是读取时的同一个 generation id，换代则拒绝本次发布。任何一个缺失、身份或执行绑定不符，目录整体不可用。来源只输出有界的业务展示字段，记录来源摘要/时刻，不能输出路径、原始 JSON、提交号、指纹或敏感参数到页面正文。Serving 在一个不可变代里封存列表和详情；Web 私有 GET 核身份、同代读取；React 对加载、不可用、失败、换代分别处理，键盘和 390px 可用。页面不伪造收益、阶段、范围和版本历史，未接通的按钮不显示。
- **兼容**：现有 Serving 来源配置的精确 6 源与 7 源清单继续有效，策略目录在这些代中明确为 unavailable，绝不把缺源解释为零条或令旧配置启动失败。新策略来源只能经显式的新来源集合版本启用；测试新源存在、缺失和读取/发布之间指针换代，不靠扩大旧清单的隐式默认值。
- **排除**：本片不授予策略执行、实验提交、晋级或编辑权限。生产 source 安装/权限和真实运行时代验证留待单独授权；只读页面完成不等于旧策略 Streamlit 单元可停。

## 验收

1. 用同一核验运行时代的三份合成安装清单和真实 `ImmutableDefinitionRegistry.read_strategy_spec` 路径核验三套策略的注册版本/参数；错 service/kind/指纹/producer commit/注册根、缺策略、篡改执行绑定、不可见记录、指针换代和超上限值都拒绝整个来源，不返回局部目录或可信零。旧 6/7 源 Serving 代继续可用而策略目录明确不可用；新来源集合有自己的显式开关与测试。
2. Serving/Web 同代读取展示字段，身份缺失拒绝；新代移除或损坏目录时不沿用旧页缓存。React 列表/详情按原型布局但只显示真实名称、注册版本及可解释参数，技术标识仅在 tooltip；无绩效/阶段假值、无无效按钮。桌面/390px/键盘与空态文案有直接行为证据。
3. 聚焦 Python/Web 测试、OpenAPI 类型产物、`pnpm -C web check`、build、`verify:dist`、固定清单增量及相关浏览器路径通过；最终候选一次独立范围内审查，P2 仅可复现违反本计划时阻断。生产源与数据代未验收时保持本地候选。
