# C7.1 绩效指标库切片

## 边界与验收

本切片只处理已算好的逐日收益与已成交记录，不读数据库、不拉行情、不写回测产物、不改页面。它为后续 C7.2 封存报告提供确定性计算层。普通任务的主要风险是指标口径错位；验收用可手算的固定序列、缺数/零分母边界、FIFO 成交核对和聚焦测试。

输入是按交易日升序、无重复、无时区且日期归零的 `pandas.Series`，值是**小数日收益**（`0.01` 代表 1%）。原始证据中的空值、无穷值、小于 -100% 的收益、重复/乱序日期都会报错。函数不插补停牌日或基准缺日，也不修改输入。返回的收益和波动率仍为小数，展示层再格式化百分比。净值从 1 开始，首个收益直接反映在首个输出点。

## 指标口径

| 指标 | 约定 |
|---|---|
| 净值、回撤 | `NAV_t=Π(1+r_i)`；峰值含初始净值 1；`DD_t=NAV_t/历史峰值-1`。最大回撤为负值，持续天数为最长连续水下**观测交易日**数，恢复日不计。 |
| 总收益、年化收益 | 末日 NAV−1；`NAV末^(252/N)−1`。一日样本数学上可算年化，解释时需提示样本短。 |
| 波动、夏普 | 日收益样本标准差（`ddof=1`）×`√252`；夏普为日超额收益均值×252/年化波动。 |
| 索提诺、卡玛 | 下行偏差为 `sqrt(mean(min(日收益−日无风险,0)^2))×√252`；索提诺为年化算术平均超额收益/下行偏差；卡玛为年化复利收益/最大回撤绝对值。 |
| 无风险利率 | 调用方传**年有效利率小数**，日值为 `(1+rf年)^(1/252)−1`，默认 0。 |
| 胜率、盈亏比 | 日收益与已平仓交易分别计算：正数笔数/非零笔数；平均正值/平均负值绝对值。交易统计使用单笔净盈亏金额，零值不进入胜负分母。 |
| 月度、滚动 | 月收益复利；无观测的月份为 `NaN`，不填 0。滚动需要完整 N 个已观察交易日，波动与夏普口径同上。 |
| 相对基准 | 只使用策略和基准日期的**精确交集**。超额总收益为策略 NAV/基准 NAV−1；年化超额以交集长度复利。跟踪误差为主动日收益的样本标准差×`√252`；信息比率为主动日收益均值×252/跟踪误差。 |
| alpha、beta | 对交集上的策略和基准日超额收益做带截距 OLS；beta 为样本协方差/基准样本方差，alpha 为日截距×252（算术年化）。无基准波动时均未定义。 |
| 年化换手 | 每个观测日单边成交额 `max(买入额,卖出额)/日初权益` 的算术均值×252。调用方提供扣除撤单后的**实际成交额**及严格正的日初权益；不把行情字段 `turnover_rate` 当作组合换手。 |
| 收益分布与连胜连亏 | 显式直方图边界，左闭右开且最后一格含右端点；范围外样本报错。给出均值、中位、5%/95% 分位；零收益中断正负连续段。 |
| round-trip | A 股整股、仅多头成交，按标的 FIFO 平仓。买入/卖出费用按匹配股数比例分摊，净盈亏除以买入额加买入费用得单笔收益。未平仓数量单独返回；按标的、**入场时行业**与自然日持有天数分组。不在分析层推定 T+1、涨跌停或撮合规则。 |

任何需要至少两个观测值的标准差或回归，在样本不足时返回 `None`；分母为 0 时对应比率返回 `None`。无观察值的总收益、年化、回撤与分布摘要返回 `None`。调用方应据此显示「数据不足」，不能当作 0 或无风险。

## 参考值与后续衔接

`tests/unit/fixtures/perf_reference_v1.json` 是实现前独立计算并冻结的四日算术参考；其他行为用可手算的两点/少量成交测试验证。当前离线环境未安装 quantstats 或 pyfolio，**尚未完成** v2 计划要求的同序列第三方库离线对照。后续在具备这两个库的离线环境生成带版本、输入和口径映射的参考 JSON，再检查差异；不能在本项目运行依赖里引入它们。尤其需核对风险自由利率、Sortino 下行偏差、alpha 年化及 pyfolio round-trip 的定义差异。

本切片不声称 C7.2 报告页或 C7.3 导出已完成；C6.1/C6.2 的日线回测产物与基准数据接入后，由产物适配器传入本模块。跨层产物结构届时用 Pydantic 定义。
