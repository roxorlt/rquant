# 因子检验：可发布的紧凑结果产物

把已成功的因子检验结果接到 React 页面之前，先封存一份小而完整的展示视图。现有研究原件最多 128 MiB，包含逐股输入并在读取时重算；它由 Lab 私有 UID 持有，Web 不应直接读该目录。后续 Serving 只发布从紧凑产物核验出的统计与曲线，网页只读同一数据代。本片完成紧凑产物和账本绑定，不改 Serving、Web 或 React。

**任务分级：高风险。** 若展示产物能与研究原件脱钩，页面可能把伪造的 IC 或分组收益标成已验证结果。以下为冻结的失败模型；先做一次 SPEC 独立审查，最终候选做一次独立终审。

## 冻结失败模型

- **资产与边界**：已验证的 `HistoricalFactorResearch`、完整内容寻址研究原件、从 `FactorResearchResult` 派生的紧凑展示模型、私有产物根、`FactorEvaluationCompletion` 与 SQLite 账本终态。计算/封存/账本属于 Lab；Web 不能读取私有原件或自己重新计算指标。发布者今后只接受账本成功回执绑定的紧凑产物。
- **失败路径**：从原型或内存中的未验证值生成曲线；摘要/日期/顺序错配；缺样本被填成零；只封存了完整原件而紧凑文件写入失败；紧凑文件被替换、截断或改字段；完成前后文件代变化；同一规格重跑生成不同摘要；旧完成记录没有新字段；只核对紧凑文件自己的 hash 却没证明它来自完整原件；Web/Serving 读取完整 128 MiB 原件或跨 UID 放宽私有目录权限。
- **必须保持**：一个纯函数从已验证 `FactorResearchResult` 生成确定性、有限大小的展示模型，只包含定义/请求摘要、统计状态与数值、逐期 IC/累计 IC、1–10 期衰减、3/5/10 组累计收益与换手、逐日覆盖/缺数原因；缺统计或未成熟收益明确为 `null`/状态，不变成 0 或“有效”。展示模型绑定完整原件 SHA、结果 SHA、因子精确版本、代码 revision 和研究来源/可见性口径；对相同完整原件逐字稳定。私有文件沿用完整原件同等级的 FD、单链接、所有者、权限、无替换和内容寻址核验，设置独立 8 MiB 上限。runner 先从同一已验证研究结果封存完整原件，再封存展示文件并重读；账本 `complete` 在同一事务前核验两个文件，**从完整原件重新投影后逐字段比较展示模型**，才保存两份 digest/大小及完整回执。历史成功记录的旧形状 `completion_json` 只能在读取路径解析为 `display_unavailable`；所有新的 `complete` 必须提供完整展示 digest/文件名/大小，缺任一项均拒绝，不得因模型兼容旧记录而把新任务写成无展示产物的成功。任一文件缺失/损坏、摘要或来源不一致不写成功；崩溃留下的单边文件可由相同规格重试复用，不删除可信文件。租约时钟与 fencing 沿用已审查账本；核验过程中到期仍拒绝完成。
- **排除**：本片不创建新的常驻服务、不开放网页或生产目录、不迁移现有旧成功任务、不改变研究指标算法/统计口径。旧回执保持可解析且显式 `display_unavailable`，不静默伪造展示数据；待生产启用前另定一次性补建方案。没有完整产物证明的统计绝不发布。

## 合同与验收

1. 新建因子领域 `display_artifact`：有类型不可变模型、纯投影函数、内容寻址写入与只读核验。曲线顺序、区间、状态和样本覆盖来自同一 `FactorResearchResult`，无前端专用重新计算；累计 IC 若领域结果没有该字段，只能由已验证逐期 IC 做明确定义的累加，并标注是累计相关系数之和，不称收益。模型的字段预算和序列长度以现有最大 1,024 期为上限，超过字节上限整次拒绝。
2. `run_factor_evaluation_job` 回执增加已封存展示文件的精确 digest/文件名/大小；`FactorEvaluationJobLedger.complete` 对**新写入**强制这三项齐全，把两份产物和规格共同核对后才持久记录。旧完成回执只在读取已持久成功记录时兼容，展示状态不可用；不能凭旧回执猜测新文件。单次 worker 不改终态规则，只调用增强后的 runner/ledger。后续发布者读取紧凑文件时仍需严格核验账本成功记录与两份 digest 绑定。
3. 红测覆盖手算 IC/衰减/分组/换手和缺样本，重排输入的稳定性，原件/展示互换、缺失、截断、符号链接、字段篡改、8 MiB 上限、账本核验中到期、完整原件已封存而展示失败后重试。另以旧 `completion_json` 证明历史成功任务可读但不可展示；对当前运行任务传旧形状或只带部分展示字段的 completion，`complete` 必拒绝且任务保持 running。成功链从合成冻结来源运行到两份私有文件、账本持久成功，重启后用外部身份读回。只跑直接相关因子与账本回归、Ruff、diff；无生产或无关全量。
