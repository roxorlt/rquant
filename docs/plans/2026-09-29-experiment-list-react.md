# 实验记录只读列表：冻结失败模型（2026-09-29）

## 范围与数据来源

- 本增量只公开实验登记库里已经存在的尝试状态和结果摘要。原型的「实验记录」表格是目标；当前登记库没有策略显示名、参数正文、夏普、年化或可比较的净值曲线，页面不补造这些事实。
- 注册库是唯一权威。研究侧来源发布器通过既有 `ExperimentRegistryReadonlyReader` 的已验证 SQLite 只读连接，在**一次事务**里读取晋级记录和最近最多 500 条完整实验尝试，再读取第 501 条仅判定是否还有更早记录。每条保留尝试的状态、结果与调整证据在这次事务内取得，绝不把分次分页读取拼成一个数据代。超限窗口显式记录「仅显示最近 500 条」和最早保留时刻；不谎称全库完整。保留窗口任一行损坏时拒绝整个来源发布。
- 来源仅投影展示所需的实验身份、研究假设、登记/完成时刻、状态及已有收益、回撤、胜率、交易数；不传播 SQLite 路径、凭据、错误原文、原始 JSON、参数或代码哈希。投影有行数/字节上限，保存于不可变 Serving 数据代。Web 只能借用一个已核验的数据代，按 `(registered_at, experiment_id)` 稳定键集分页。

## 信任边界和失败路径

- **注册库 → 研究发布器**：文件/父目录/WAL 代际或 schema/索引校验失败、旧库缺新增索引、保留窗口行或关联结果失配都使来源不可用；不能把缺源、坏行或超过窗口解释为零条。已有索引的生产补建属于数据库迁移，另需 owner 明确授权，不在本切片执行。
- **研究来源 → Serving**：保留原有来源鉴权及内容散列；投影只带预定义列，时间不得超出发布时刻，重复身份、乱序、过量及过大载荷拒绝发布。旧来源或旧数据代没有实验投影时显式为「暂时读不到实验记录」，不显示空表；可信的零条有已发布空投影和可用状态。
- **Serving → Web**：请求只从一次借用的数据代读取状态和行。后续页必须携带该代身份及严格边界；数据代已切换返回冲突并要求从首批重取。分页上限 50，键集游标与代绑定且不能跳至另一来源。Web 不直接打开注册库或主库。未验证的代理身份不能读取。
- **Web → 浏览器**：加载、无数据、不可用、请求失败和数据代切换是不同状态；页面不把状态回执当成结果发布。实验标识可作接口键，不在正文展示哈希。窄屏和键盘操作必须可用；不存在的写命令不显示为可执行。

## 不变量、验收与排除项

- 同一数据代内最近窗口全量来自一个 SQLite 快照；顺序确定、无重复、无静默截断。保留窗口任何损坏都不能产生部分成功页面。超过 500 条时公开截断事实和覆盖起点；旧记录尚不可在本页查看。注册截止和状态可见时刻都是发布时刻，历史回放不在本次范围。
- 仅显示已存储的净收益、最大回撤、胜率和交易数。未发布的策略名、参数正文、夏普、年化、备注分别标明不可用；不从指纹猜测值。
- 本切片不提供新建/登记写入、备注编辑、两实验比较、参数热力图、PSR/DSR/PBO、任务启动、生产索引迁移或切流。后续能力须接对应权威产物及受控命令后才启用。
