# 集合竞价跳空策略特征归因（roadmap #10）

**日期**：2026-07-02
**数据集**：`rquant auction-gap-minute-replay --start-date 2025-04-28 --end-date 2026-06-30`
共 2281 候选 / 1028 笔成交（触发率 45.1%），训练段 708 笔（≤2025-12-31）/ 验证段 320 笔（2026-01 起）。
**基准**：均收益 **-1.78%** / 胜率 31.0% / 中位 -1.94%（费前）。

> ⚠️ 数据修复记录：7/2 主库覆盖事故除盘中 rt 数据外，还吞掉了 6/26 回补的
> 2026-04-16~06-24 候选分钟线（12.1 万行，从未进过只读副本）。本报告基于修复后
> 数据（重新回补 265 候选 / 12.58 万行）。修复前的回测在 2026 年 5-6 月触发率
> 假性坍缩（134 笔 → 14 笔），任何基于修复前数据的结论作废。

## 1. 核心发现：盈亏完全由「收盘封板」决定，而入场位置决定赔率

B 日结局拆解（全样本）：

| 结局 | 笔数 | 均收益% | 胜率% |
|---|---|---|---|
| 收盘封住涨停 | 456 | **+3.33** | 59.4 |
| 未触板 | 571 | **-5.87** | 8.4 |
| 触板未封 | 1 | -2.93 | 0 |

（注：`b_hit_limit_up_today` 实际是收盘口径，数据里"触板未封"近乎不存在。）

**关键交叉结构**——入场时涨停进度（`entry_signal_limit_progress`）× 是否封板：

| 入场进度 | 封板率 | 封住均收益% | 没封均收益% | 分箱期望% |
|---|---|---|---|---|
| <0.5（低位确认） | 20.6% | **+6.45** | -3.86 | -1.73 |
| 0.5-0.8 | 39.2% | +3.07 | -7.86 | -3.58 |
| 0.8-0.95 | 61.4% | +3.64 | -7.15 | -0.98 |
| 0.95-1 | 55.9% | +2.30 | -9.56 | -4.30 |
| =1（贴板打板） | 73.9% | +2.31 | **-10.21** | -0.96 |

解读：

- **低位入场是"低胜率高赔率"**：封板率只有 1/5，但封住赚 6.45%、失败只亏 3.86%。
- **贴板入场是"高胜率灾难赔率"**：封板率 74%，但利润已被入场成本吃掉（+2.31%），
  一旦炸板次日均亏 **-10.21%**。
- **每一个分箱的期望都是负的**。当前入场逻辑（`auction_gap_vwap_push` + T+1 次日
  退出）没有正期望角落，问题不在挑哪个位置入场，而在策略结构本身。

## 2. 单变量归因：没有特征能直接预测收益，一堆特征能预测封板

训练段 |spearman(ret)| 全部 ≤ 0.12——**没有任何单一入场特征线性预测收益**。
但预测封板的特征很多（Q5-Q1 封板率差）：涨停进度 +53pp、竞价跳空幅度 +35pp、
入场分钟成交额 +24pp、竞价量比 +18pp。收益差却同时≈0——因为封板概率的提升
被入场价的抬升精确抵消（见第 1 节交叉表）。这是拥挤交易的典型特征。

**未能检验的特征**（路线图原本最看好的方向）：`同分钟历史相对放量` /
`截至同分钟累计成交额相对历史` / `5/10 分钟加速度` 在 82-97% 样本上为空——
它们需要信号日前 20 个交易日的分钟线，现有回补只覆盖 B 日到退出窗口。

## 3. 过滤规则搜索：最优规则只能打平，费后仍不可交易

训练段网格选优（单特征 + 双特征，阈值取训练分位数），验证段一次性评估：

| 规则 | 训练均收益% | 验证笔数 | 验证均收益% | 验证胜率% |
|---|---|---|---|---|
| 进度≥0.87 且 分钟成交额≤1.09亿 | -0.02 | 55 | **+0.21** | 38.2 |
| 距涨停≤6.84% 且 分钟成交额≤7150万 | -0.29 | 74 | -0.21 | 32.4 |
| 其余（略） | -0.3~-0.5 | — | -0.15~-1.32 | — |

最优规则 = 「贴板 + 轻量」：命中 185 笔、封板率 77.3%、全样本均收益 +0.04%。
相对基准 -1.78% 提升约 1.8pp，方向真实（验证段同向），**但 A 股双边成本约
0.2-0.4%，费后依然为负**。结论：现有特征集合内不存在能把该策略修成正期望的过滤。

## 4. 一个值得留意的正向信号：封板时长

触板样本按 `b_limit_up_close_minutes`（封板分钟数）四分位：Q1 均收益 +2.96% →
Q4 **+3.81%**。封得越久，次日（T+1 退出）越强。这不是入场特征（收盘才知道），
但适用于**持有期决策**：封板质量高的仓位值得持有超过 1 天——当前回测
`max_hold_days=1` 可能整体低估了策略上限。

## 5. 结论与下一步决策项

1. **原始竞价跳空 + VWAP push + T+1 退出：判死**。全区间 1028 笔、每个入场位置
   分箱、每个可搜索的过滤角落期望均为负，最优过滤费后打平。
2. **决策项 A——回补 20 日 lookback 分钟线**（约 4 万次 stk_mins 请求，积分不
   消耗只耗时约 4-6 小时）：解锁「相对放量」特征族，这是路线图原本的核心假设，
   目前 90% 样本为空、从未被真正检验。不补，#10 归因就只能到此为止。
3. **决策项 B——改造持有期**：基于封板时长的持有期扩展（封住且封板>N 分钟 →
   持有 2-3 天）值得单独回测，第 4 节信号 + N 字策略池的既有逻辑都指向这里。
4. **决策项 C——放弃该策略线**，研究资源转回 N 字主线（Pool1/Pool2 的分钟级
   B/S 优化），竞价特征仅作为 N 字候选的辅助排序因子（竞价跳空幅度对封板率
   +35pp 的区分度可以直接复用）。

## 复现

```bash
# 数据集
.venv/bin/rquant auction-gap-minute-replay \
  --start-date 2025-04-28 --end-date 2026-06-30 --output /tmp/replay.csv

.venv/bin/python scripts/analyze_auction_gap_attribution.py /tmp/replay.csv
```

注意：`stk_mins` 1 分钟历史地板为 2025-04-28，更早区间无法回测。

## v3 补充（2026-07-02 深夜，数据全景到位后复验）

数据升级：日线/复权 2020-08-24 起全市场、官方涨跌停榜（limit_list_daily）2020 起、
市场温度 1416 天、候选 lookback 分钟回补完成（分钟线 1900 万行）。样本 1034 笔。

**决策项 A 的答案：相对放量特征检验完毕，不能救活该策略。**
`rel_cum_amount_asof_20d` / `rel_amount_same_minute_20d` 覆盖从 25% 升到 99% 后：
对封板率 +30.5/+26.2pp（预测触板 ✓），对收益 spearman -0.073/-0.071（**与绝对量能
同构，负向**）。路线图「同分钟历史放量选好票」的核心假设在收益维度不成立。

**市场温度（60 日新高占比 / MA20 上方占比 / 涨停家数 / 上涨占比）单变量全部弱相关
（|ρ| ≤ 0.041）**；涨停家数还是负向——涨停潮的日子该策略更拥挤更差。温度作为该
策略的门控无效（不代表对 N 字主线无效，待另测）。

规则搜索最优仍为「贴板 + 轻量」（验证段 +0.21%），新特征未产生更优规则。

**最终结论**：该策略线所有设想特征已穷尽检验，判死结论升级为终审。有效路径只剩：
- 决策项 B：封板质量驱动的持有期扩展（官方 fd_amount/open_times 数据已就位）
- 决策项 C：竞价强度 + 封板强度特征迁移给 N 字主线做排序因子
