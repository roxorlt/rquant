## 一、封板质量条件持有：方向真实、幅度不足，竞价跳空策略维持判死

7 组网格（baseline T+1 vs seal_hold_days ∈ {2,3,5} × max_open_times ∈ {0,1}，
封板质量优先官方 limit_list_daily，缺行回退分钟推算）：

- 全区间最优 seal5d_open1：**-1.58% vs baseline -1.70%（+0.12pp）**，
  训练/验证同向、随持有天数单调改善——信号方向真实
- seal_hold 触发子集自身 +4.79%~+5.16%，但平均实际持有仅 1.1~1.2 个交易日：
  封板日移动止盈线已按板价上移，次日盘中就被 take_profit / 竞价弱退带走，
  时间上限极少真正约束退出——**延长持有的收益早已被现有风控体系吃掉**
- 结论：+0.12pp 盖不住 0.2~0.4% 双边成本。竞价跳空入场结构负期望的判死
  维持不变（与 2026-07-02 归因终审一致），资源按决策项 C 转 N 字主线。
- 顺带修复：auction_bar 偶发 price=0 坏行造成假 -100% 亏损（已加守卫+回归测试）；
  77% 候选多日窗口分钟缺失 → 新增日线降级退出路径（exit_daily_fallback 标记）。

## 二、评分画像 V2：低位百分位因子有真实小幅增益，温度门控被证伪

n-shape-combined，2026-01-01~06-30，验证段 = 后 30%：

| 结论 | 证据 |
|---|---|
| `price_percentile_250d` 低位方向有效 | top3 验证段 +1.58% vs V1 +1.34%；最优组合 +1.75% vs 同组合 V1 +1.00%；动量方向（高位加分）一致更差——**N 字低位首板假设被双向验证** |
| 多数情况不改变选中集合 | 候选池小，因子只在边际分歧处起作用，增益真实但幅度有限 |
| 市场温度门控（<30 跳过）证伪 | 验证段 0 笔全被门掉，而被门日实际 +1.87%/胜率 56.5%——训练段有效、验证段翻转，**regime 不稳定**。机制保留（env_gate），默认不启用 |
