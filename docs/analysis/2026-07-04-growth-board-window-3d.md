# 板块集合竞价额历史窗口：20 日 → 3 日

**日期**：2026-07-04
**数据**：只读副本，全市场创业/科创；训练段 ≤2025-12-31 / 验证段 2026-01+；费前。
**背景**：v3 报告里板块集合竞价强度闸门被判「噪音」——训练段负贡献、验证段勉强正，
符号在两段间翻转。本次把板块竞价额的历史比较窗口从 20 日缩到 3 日重跑，
验证「短窗口是否更能抓当下资金青睐」。9:30 早入固定打底，其余条件不变。

## 一、口径改动

原先板块竞价额相对历史的比较窗口**误复用了核心爆量因子的 `lookback_days`（20）**，
改板块窗口会连带改爆量同刻中位口径。本次将其解耦为独立字段 `board_hist_days`，
`board_auction_amount_ratio = 板块当日竞价总额 / 该板块过去 board_hist_days 日竞价总额中位`。
其余（题材成分按 ≤T 最近打点还原、竞价 09:25 已知）不变，仍无未来函数。

## 二、20 日 vs 3 日（同三档阈值，g=高开占比下限/a=竞价资金比下限）

| 阈值档 | train Δ均收益% | val Δ均收益% | full Δ均收益% |
|---|---|---|---|
| g50a10 | +0.53 | +0.50 | +0.51 |
| g50a13 | +0.38 | +0.05 | +0.31 |
| g60a10 | −0.07（噪音级） | +0.94 | +0.40 |

（Δ = 3 日窗口 − 20 日窗口。）**3 日窗口全面 ≥ 20 日**，g50a10/g50a13 训练段就更好，
g60a10 训练段几乎打平（−0.07，噪音级），验证段大涨。窗口缩短不是靠验证段挑出来的。

## 三、与 9:30 裸基线的关系被改写（关键）

| 变体 | train（基线 2.96） | val（基线 1.09） | val 笔数 |
|---|---|---|---|
| g50a10 · 窗口20 | 2.54（**负 0.42**） | 0.92（负 0.17） | 83 |
| **g50a10 · 窗口3** | **3.07（正 0.11）** | **1.41（正 0.32）** | 79 |
| g50a13 · 窗口3 | 2.77（负 0.19） | 1.18（正 0.09） | 52 |
| g60a10 · 窗口3 | 2.14（负 0.82） | 2.38（正 1.29） | 61 |

- **20 日窗口下所有档在训练段都是负贡献**——正是 v3 判「噪音」的依据（训练/验证符号翻转）。
- **换 3 日窗口后，g50a10 训练段首次翻正（+0.11），训练/验证同向**：从「噪音」升级成
  「弱但方向一致的真信号」。经济含义讲得通：板块资金青睐是**短周期情绪**，20 日中位把它
  摊平、稀释掉当下强弱；3 日窗口才抓得住「这两天资金是不是真在往这个板块灌」。
- g60a10·窗口3 验证段最高（2.38%），但训练段仍比基线低 0.82%——单看仍是过拟合特征，
  那个 2.38 不可信。g50a13·窗口3 训练段仍负 0.19，也未完全翻正。

## 四、别高估（诚实边界）

- g50a10·窗口3 对裸基线的增益仍薄（train +0.11 / val +0.32），代价是砍掉 89% 交易
  （val 748→79），约 13 笔/月，样本稀。
- 中位数各档仍全负（−0.78 ~ −1.72），靠少数大赢家抬均值——板块门没改掉 >50% 亏损率的
  底层入场结构，它是**选择性/降尾部过滤器**，不是收益引擎。
- 费后（双边 ~0.3%）：g50a10·窗口3 val ~1.11% vs 基线 ~0.79%，净增益 ~0.32% 勉强存活。

## 五、裁决

3 日窗口是对「板块闸门」这个**可选过滤器**的真实改进——训练段就成立（非事后挑），
把默认 `board_hist_days` 从 20 改为 3。但板块闸门本身仍是**可选**（`require_board_favor`
默认关），不升级为策略默认闸门：它对裸 9:30 基线的增益薄、砍样本狠，只在需要更高选择性
或压尾部风险时开启。

## 复现

```bash
# 3 日窗口（现默认），板块闸门可选开启
rquant growth-board-surge-replay --require-board-favor \
  --min-board-gap-up-ratio 0.5 --min-board-auction-amount-ratio 1.0 \
  --board-hist-days 3 \
  --start-date 2026-01-01 --end-date 2026-06-30
# 对照 20 日窗口
rquant growth-board-surge-replay --require-board-favor \
  --min-board-gap-up-ratio 0.5 --min-board-auction-amount-ratio 1.0 \
  --board-hist-days 20 --start-date 2026-01-01 --end-date 2026-06-30
```
