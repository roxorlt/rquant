## W5 · 封单因子:✅ 训练/验证双集单调,强验证

脚本:[`seal_factor_daily.py`](seal_factor_daily.py)。样本:涨停 52,062 条,可对齐 38,130(训练 28,183 / 验证 9,947)。因子 = 收盘封单额/流通市值(封成比)五分位,按日横截面分组。

**T+1 开盘溢价(核心结果,完美单调且验证集复制)**:

| 五分位 | 训练集均值/胜率 | 验证集均值/胜率 |
|---|---|---|
| Q1 最弱封单 | +0.41% / 51% | +0.73% / 57% |
| Q3 | +2.39% / 70% | +1.65% / 63% |
| Q5 最强封单 | **+4.77% / 79%** | **+3.56% / 72%** |
| **Q5−Q1** | **+4.36pp** | **+2.83pp** |

**开板次数(直接验证 §3.6 的炸板逻辑)**:

| 分组 | 训练集开盘溢价 | 验证集 |
|---|---|---|
| 一字未开板 | +3.33% / 74% | +2.26% / 65% |
| 开板 1 次 | +2.35% / 66% | +1.68% / 60% |
| 开板 ≥2 次 | **+0.85% / 53%** | +1.32% / 61% |

**最有操作价值的发现——溢价全在隔夜,次日日内是负的**:

| T+1 持有段 | 训练集 Q5 | 验证集 Q5 |
|---|---|---|
| 隔夜(收→开) | +4.77% | +3.56% |
| **次日日内(开→收)** | **−0.95%** | **−0.64%**(且日内按 Q5→Q1 反向单调) |

三条策略含义:
1. **规格 C1 分支(封死涨停→锁仓持有至 T+1)拿到了量化背书**:收盘封单越强,隔夜溢价越高、越该持有过夜;
2. **T+1 的最优默认动作是开盘附近卖出**,不是持到收盘——封单最强组次日日内平均回吐约 1 个点。这与规格时段 A 的「冲高不封板减仓」方向一致,且给了更强的版本:除非 A1(再次封板),开盘溢价应尽快兑现;
3. **炸板 ≥2 次当日拉黑**(§3.6.2 的 `max_broken_count=2` 占位值)在日频数据上成立:开板 ≥2 次组的隔夜溢价只有一字板的 1/4。

**边界诚实声明**:本验证用的是**收盘时点**的封单快照(T 日收盘已知,预测 T+1 开盘,无未来函数),回答"要不要持有过夜";它**不能**回答"盘中封单衰减时该不该立即卖"——那需要盘中封单序列(P4,数据源 `rt_k` 或 iTick depth)。另外样本不含 ST(tushare limit_list_d 口径)。
