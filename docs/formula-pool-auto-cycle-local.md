# 公式池单日自动推进（本地受信入口）

本入口复用[整日协调器](formula-pool-batch-local.md)的 owner-private 配置和现有共享任务 worker。它先核验指定交易日的全部公式池，然后最多执行 1–8 次已准入任务；每次 worker 调用后均重新核验完整目录，包括 worker 返回 `None` 的情况。任务之间不休眠或轮询，不跨日，也不自行寻找最近交易日。

在仓库根目录、已配置本地合成或其他明确授权的数据路径时运行：

```bash
PYTHONPATH=src python -m rquant.formula_pool_auto_cycle --config /absolute/private/batch.json --trade-date 2026-04-16 --max-worker-calls 4
```

`--config` 必须是现有规范、当前用户拥有且权限为 `0600` 的私有批处理配置；名单、行情、任务状态和结果目录只从该配置读取。`--max-worker-calls` 可取 1–8，默认 8。输出 JSON 包含实际 `worker_calls` 和重新核验后的完整 `day` 状态。已有可信结果或可信空目录的调用次数为 0。`day.all_complete` 只有在全部定义的目标日封存结果与同一目录、名单、行情身份一致时才为真；失败、等待和零命中沿用协调器的原有口径。共享队列中其他研究任务可能被执行，但不会算作公式池完成。

返回码 `0` 表示输出了可信状态，可能仍有等待或失败；调用方应读取 `day.all_complete`。返回码 `1` 表示目录、来源、执行或身份核验失败，不输出部分 JSON；`2` 表示配置、日期或调用次数输入无效。不应仅凭返回码 `0` 宣称全部完成。达到调用次数上限或 worker 空闲后可再次运行同一日期；持久任务幂等键和不可变逐日结果保证重试继续沿用现有证据。

此入口没有生产 timer、线上默认配置或服务安装。正式路径、运行账号、资源预算及发布需单独完成验收和授权。
