# rQuant 组件用在哪

> 设计规范 v0.1 附表，2026-10-20，按改版后的设计整理（不是现状）。页面写中文名。
> 组件样式见 [components.css](components.css)，变量见 [tokens.css](tokens.css)，各状态示例见 [规范页](index.html)，改后示意见 [市场全景](../mockups/panorama.html)、[总览](../mockups/overview.html)、[个股档案](../mockups/stock.html)。

## 外框

| 组件 | 用在哪些页面 | 端 | 说明 |
|---|---|---|---|
| 全局顶栏（含页面标题） | 全站 | 都 | 电脑 52px、手机 48px 单行；页面标题进顶栏，取消眉标；副标题一行可省略 |
| 左侧导航 | 全站 | 电脑、平板 | 600px 及以上 212px 文字导航；599px 及以下改用底部标签栏 + 「更多」；当前页用主色浅底 |
| 手机底部标签栏 | 全站 | 手机 | v1.1：4 个标签（全景、资金流、池子、更多），56px，避开底部安全区；手机默认打开池子（池子选中），平板和电脑默认打开总览（产品负责人确认） |
| 「更多」弹层（.more-sheet） | 全站 | 手机 | v1.1：只列不在底栏的 15 页，总览第一行；告警行带未读数，健康行带状态文字 |
| 顶栏告警铃铛（.bell + .badge） | 全站顶栏 | 手机 | v1.1：44px 点按区；角标 = 最近一个交易日未确认的告警数（点「确认」才减 1，打开告警页不变，15 秒刷新），1–99 / 99+，0 不显示（产品确认） |
| 顶栏健康状态点（.hstat） | 全站顶栏 | 手机 | v1.1：44px 点按区；正常 / 注意 / 异常三种形状，aria-label 写状态；某层未知、整体读取失败都显示「注意」菱形，文字写「未知：读不到数据」/「未知：健康状态读取失败」（产品确认） |
| 搜索框 / 搜索图标 | 全站顶栏 | 都 | 电脑 240px 输入框；手机只放图标，44px 点按区 |
| 页面标题条（.pagebar） | 顶栏放不下操作的页：选股器、个股档案 | 都 | 标题不换行；步骤条、按钮放不下就移到第二行或「更多」 |

## 基础组件

| 组件 | 用在哪些页面 | 端 | 说明 |
|---|---|---|---|
| 按钮（.btn 主要、次要、文字；禁用、加载） | 全站 | 都 | 一个区域最多一个主要按钮；文字是动作本身（去盯盘、保存方案、看健康）；手机 44px |
| 分段控件（.seg） | 市场全景（赚钱效应 / 涨停炸板切换）、个股档案（日K / 分时 / 5日）、板块资金流 | 都 | 放进面板标题行，不单独占一行；手机 44px 高（v1.0 起）、不撑宽页面 |
| 标签页（.tabs） | 宏观（总览 / 资金 / 情绪 / 事件研究）、个股档案（概览 / 财务 / 资金 / 公告） | 都 | 切换整块内容；超过 3 屏的页面必须分区 |
| 指标条（.mstrip / .m） | 总览、市场全景、板块资金流 | 电脑 | 2–8 个同级数字一条，56px；每页最多一条；每指标 ≤ 7,000 px² |
| 指标条手机写法（3 列网格） | 总览、市场全景、板块资金流、个股档案（6 个关键指标） | 手机 | ≤ 6 个 3 列最多 2 行；7–12 个单行横滑；不留空格子 |
| 涨跌分布条（.breadth） | 市场全景、板块资金流；总览「市场速览」（待定） | 都 | 宽度即比例，红涨、灰平、绿跌 |
| 指标网格（.mgrid） | 个股档案（29 项，按行情 / 成交 / 估值 / 区间分 4 行） | 电脑；手机点「全部 29 项」展开 | 键左值右，行高 28px，值右对齐 |
| 大数字（.hero） | 个股档案现价 | 都 | 每页只有一个；电脑 32px、手机 28px；涨跌和时间同行 |
| 面板（.panel） | 全站 | 都 | 靠底色区分，不加阴影和描边；面板间 12px |
| 表格（.tbl） | 市场全景行业表、宏观事件研究、回测、系统健康、选股器结果、数据查询 | 电脑 | 紧凑 28px；数字列右对齐、单位进表头；不能撑出页面横向滚动 |
| 两行列表项 | 市场全景行业、选股器结果、回测、盯盘与告警、系统健康 | 手机 | 替代宽表：第一行名称 + 代码，第二行 2–3 个数，右侧最关键的数；整行 44px 以上可点 |
| 可横滑标签条 | 选股器方案标签 | 手机 | 单行横滑，44px，选中项滚入可视区 |
| 输入（.field / .input） | 选股器条件、保存方案、个股代码搜索 | 都 | 错误写在框下方；手机字号 16px |
| 状态点（.st） | 总览今日链路、需要关注；系统健康 | 都 | 圆点加文字（正常 / 提醒 / 需处理），不单靠颜色 |
| 提示条（.notice） | 数据过期、读取失败、研究结果仍是「探索性」；只读账号：选股器、盯盘与告警、池子页面顶部 | 都 | 写清原因和下一步，带「重试」或「看说明」；只读账号用中性 .notice，不带操作、不能关 |
| 专业词解释（.tip / .tip-pop） | 市场全景（炸板、上涨占比、涨跌中位数）、成交额精确值（待定） | 都 | 虚线下划线；电脑悬停、手机点按 |
| 加载、空、错误（.skel / .empty / .error） | 全站 | 都 | 骨架尺寸同真实内容；空状态写为什么空和下一步；空表不画表头 |
| 迷你走势（.spark） | 市场全景行业表行尾 | 电脑 | 64×20，虚线为昨收，不加坐标轴 |
| 文本截断（.ellipsis / .clamp-2 / .break-id） | 总览环节说明、需要关注、各页副标题 | 都 | 数字永不换行；长标识最多 2 行，全文放悬停 |
| 等宽数字（.num）和涨跌色（.up / .down / .flat） | 全站所有数字 | 都 | 窄体等宽数字；正数带「+」，负数用「−」；只给相对昨收的数上色 |

## 业务组件

| 组件 | 页面 | 端 | 说明 |
|---|---|---|---|
| 今日链路（6 个环节，每格名称 + 状态） | 总览 | 电脑 | 并进指标条，详情在悬停提示 |
| 今日链路摘要（「2 个环节需处理，4 个正常」+ 展开） | 总览 | 手机 | 展开后每环节一行 44px，需处理的在前 |
| 需要关注列表 | 总览 | 都 | 状态 + 问题名 + 一行说明 +「看健康」 |
| 最新告警、最新信号 | 总览 | 都 | 空时用空状态，带「去改规则」 |
| 赚钱效应图 | 市场全景 | 都 | 逐分钟上涨家数占比 |
| 行业热力图 | 市场全景 | 都 | 电脑在右栏吃满剩余高度；面积 = 成交额，颜色 = 涨跌中位数 |
| 个股抬头（名称、代码、行业、加入自选 + 现价行） | 个股档案 | 都 | 一行；手机「全部 29 项」入口放在现价行 |
| K 线面板（周期分段、开高低收、均线） | 个股档案 | 都 | 手机首屏必须露出 |
| 区间涨跌行（5日 / 20日 / 60日 / 250日 / 年初至今） | 个股档案 | 都 | 周期在上，带色涨跌在下 |
| 明细表 20 行 +「展开全部（共 N 行）」 | 宏观事件研究 | 都 | 配筛选、排序或分页 |
