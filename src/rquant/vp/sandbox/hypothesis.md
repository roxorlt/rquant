# 研究假设卡

规格 §7.1。**每个实验一张卡，跑之前写完**——「预期结果」跑完再填就没有证伪价值了。
新实验往下追加，不要覆盖旧卡；卡片编号与 `experiment_log.csv` 的 `hypothesis` 列对齐。

## 模板（复制下面整段，不要删任何一栏）

```markdown
## 假设 H-{编号}

**市场观察**：{一句话，可证伪}
**可能机制**：{为什么可能成立——标注这是待验证解释，不是事实}
**信号定义**：{精确到可以直接写代码}
**数据时间**：{用了哪天的什么数据；最早可交易时刻}
**预测目标**：{从什么时刻到什么时刻的收益}
**基准**：{至少 3 个，见 §5.6}
**混杂变量**：{市值/行业/beta/波动/流动性/单一时段}
**失败标准**：{什么证据出现就承认无效，见 §6.3}
**预期结果**：{跑之前写死，跑完对比}
```

## 填写要点（踩过的坑）

- **数据时间**这一栏是未来函数的唯一防线：写「最早可交易时刻」，不是「数据描述的
  时刻」。分钟数据在当根结束后 3–60s 才可得，T-1 分钟数据在 T 日 9:15 前是否 100%
  可得尚未实测（规格 §2.2 的三个 ⚠️ 实测项）。
- **失败标准**必须在跑之前写死，且要具体到数字。「效果不好就放弃」不是失败标准。
- **基准**至少三个（规格 §5.6），只跟 0 比等于没比。
