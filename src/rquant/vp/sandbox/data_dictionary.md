# 数据字典（沙盒新增字段登记）

规格 §2。**任何字段进入策略前必须先在此登记，八列缺一列不得使用。**
本文件只登记沙盒实验新增的字段；策略主干字段在规格 §2.2，以那份为准。

## 八列登记表模板

| 列 | 含义 | 为什么必须 |
|---|---|---|
| `field` | 字段名 | — |
| `meaning` | 业务含义 | — |
| `unit` | 单位 | rQuant 已踩过坑：`daily_bar.amount` 是**千元**，`rt_min.amount` 是**元**，差 1000 倍 |
| `freq` | 频率 | 日 / 1min / 3s / tick |
| `available_at` | **实际可用时间** | 不是「数据描述的时刻」，是「这条数据最早能被程序读到的时刻」——未来函数的唯一防线 |
| `adjust` | 复权口径 | 不复权 / 前复权 / 后复权 / 不适用 |
| `revised` | 是否有后期修订 | 财务数据会修订，行情数据一般不会，但**停牌/除权会改写历史** |
| `missing` | 缺失语义 | NaN 代表停牌？未上市？接口失败？三者处理完全不同 |

## 复权口径的死规定（规格 §2.3）

**VP 计算一律使用「不复权原始价格 + 除权日重置锚点」，禁止使用前复权。**
前复权序列会随每次除权改写历史价格，同一份代码不同日期跑出不同结果，且等于用了
未来才知道的除权因子。个股在窗口内除权除息 → 所有跨日 VP 从除权日重新起算，
除权日当天不产生买入信号。
